# メニュー名の日本語と英語の併記

`before-after.png` は、変更前と変更後の **VR Vlog** メニューです。上がメニューバー、下がHierarchyの右クリックです。

- 環境: Unity 2022.3.22f1、Windows、表示倍率100%（96DPI）
- シーン: 新規シーンに、Animatorだけを付けた `Avatar` を置いて選択した状態
- 撮り方: 開いたメニューをそのまま画面キャプチャし、全体を3倍に拡大した。96DPIのネイティブメニューなので、3倍の解像度では描画されていない
- 撮影後の加工: 赤枠を足した。バーとHierarchyとメニュー以外を灰色で塗り、メニューの中の他のツールの名前をぼかした
