# VRM書き出し

安定版0.11.15では、手元試験版 .6 で確認した表情・ポーズ指定の操作を、標準のVRM書き出し画面へ採用しています。

Unityの **VR Vlog → VRMを書き出す** を開きます。

1. Hierarchyからアバターを指定し、**書き出しを準備**を押します。
2. 見つかった表情は、すべて **その他の表情** に入ります。VRMの表情5枠（喜び・怒り・悲しみ・安らぎ・驚き）に使う表情を枠へドラッグ＆ドロップし、書き出さない表情は **書き出さない** へ移します。表情を押すと顔を確認できます。
3. 名前から自動で入った枠を確認し、**自動の○件をすべて確定** で確定します。
4. 作者名と従来のライセンス設定を確認し、**この割り当てでVRMを保存**を押します。
5. 保存完了欄の **QRコードでスマホに送る** → **アップロードしてQRを表示** を押し、QR受信対応のiPhone版VR Vlogの **モデルを変更 → PCから受け取る** で読み取ります。

見つかる表情はFaceEmoやアバターに登録されたControllerが実際に参照するファイルです。名前の推測で選びません。
ほかの表情は、UnityのProjectで.animを複数選択して **その他の表情** へドロップするか、**表情の.animを追加** から指定して追加できます。ALCOMに登録するのはExporter本体で、表情ファイルはUnityで指定します。

## 表情ボード

表情はどれも、VRMの表情5枠・**その他の表情**・**書き出さない** のどこか1か所に入ります。

- **その他の表情** の表情はVRMのカスタム表情として書き出します。**書き出さない** の表情はVRMに含めません。
- 表情はドラッグ＆ドロップで移します。右クリックのメニューでも移せます。カードの **×** は、枠では **その他の表情** へ戻し、**その他の表情** では **書き出さない** へ移します。
- **書き出さない** の指定は、喜怒哀楽の指定と同じくアバターごとに保存し、次に同じアバターを準備したときに戻します。
- **割り当てをリセット** は、手で割り当てた表情と書き出さない指定を消して、名前から割り当て直します。
- 表情名の変更はできなくなりました。カスタム表情はファイル名で保存します。
- **書き出さない** が0件で、.animを追加していない場合は、従来の通常の書き出しでアバターの表情を保存します。それ以外では **その他の表情** の内容をそのまま記録します。**その他の表情** の見出しの説明は、通常の書き出しでは「アバターの表情メニューをそのまま書き出し」、記録する場合は「この一覧を記録して書き出し」に切り替わります。
- 記録する場合、**その他の表情** は最大64件で、超えた分を **書き出さない** へ移すまで保存できません。同じ名前の表情が2つ以上あるときも、片方を **書き出さない** へ移すまで保存できません。**その他の表情** を全部 **書き出さない** へ移した場合は、アバターの表情メニューの表情を1つも含めずに保存します。

プレビューは画面上部に表示します。画像をドラッグすると向きを変え、ホイールで拡大できます。**元の顔**で基準に戻します。

## 収録する範囲

秒数の指定は不要です。表情はファイルの終端の値を固定の顔として保存します。最初から最後まで同じ顔の一般的な表情クリップはそのまま使え、無表情から変化するクリップは変化後の顔になります。終端が無表情に戻るクリップも終端を使うため、表情を押して結果を確認してください。動く表情全体の再生は収録しません。

任意の全身ポーズは **全身ポーズを追加** を開き、別の枠に.animをドロップします。**ポーズを確認**で見られます。静止ポーズは先頭、動くポーズは先頭から最後までを既存のポーズ仕様で保存します。表情とポーズは別々に選べるデータとして同じVRMに同梱します。同時に呼び出すプリセット機能はありません。

## 標準の表情（喜怒哀楽）

VRMの表情5枠には、VRM 1.0の標準表情 happy（喜び）・angry（怒り）・sad（悲しみ）・relaxed（安らぎ）・surprised（驚き）に使う顔を入れます。表情を枠へドラッグ＆ドロップするか、枠の見出しを押して一覧から選びます。一覧には次のものが並びます。

- **追加した表情**: Projectから追加した表情ファイル
- **FaceEmo**・**アバターのController**: アバターが実際に参照する表情ファイル
- **BlendShape**: 書き出すメッシュのBlendShapeを1つ選び、100で使います
- **なし**: その枠を空のまま保存します（元のアバターのVRM設定にある枠では **元のVRM設定**）

表情ファイルは終端の値を使います。枠に入れるとプレビューに顔を表示します。基準の顔と形が同じもの、表情以外の変更を含むものは枠に入れても保存できず、枠に理由を表示します。

- 表情ファイル（FaceEmo・FX・Gestureなど）とBlendShapeの名前から判断できる候補（`Smile`・`Joy`・`怒り`・`Fun` など）は初期値として入り、カードに **自動** と表示します。**自動の○件をすべて確定** で手で割り当てた扱いにします。**書き出さない** に移した表情は候補にしません。感情そのものを表す語（`smile`・`笑顔`）をゆるい語（`joy`・`笑`）より優先します。英語は単語単位で、日本語は名前の一部で判断します。目・口・眉・左右・ウィンク・瞬きを表す名前と、2つの表情に当たる名前は候補にしません。BlendShapeは英語の名前だけを候補にします（`怒り`・`びっくり` などMMD形式の名前は眉や目だけが動くことが多いため、手で選んでください）。
- 元のアバターのVRM設定に喜怒哀楽がある場合、その枠は **元のVRM設定** と表示し、自動候補で置き換えません。
- 自分で選んだ枠は、見出しの一覧の **自動の候補に戻す** で自動に戻せます。元のファイルが変わって保存できない指定があると、画面上部の **次にやること:** に「○○の割り当てを直す」と表示します。
- 枠のカードの **×** で、表情は **その他の表情** へ戻ります。BlendShapeの指定は外れて「なし」になり、その表情は空のまま保存します。何も指定しない場合の出力は従来と同じです。
- 自分で選んだ内容と外した内容は、アバターごとにプロジェクトの `UserSettings/VRVlogLilToonExporter/ExpressionPresets.json` へ保存し、次に同じアバターを準備したときに使います。アバター・シーン・Prefabは変更しません。保存していないシーンのアバターでは次回に残りません。元のファイルが削除された指定は外します。
- 記録した表情は従来の名前（`VRChat / 記録 / <名前>`）のカスタム表情のまま残し、標準表情は別の表情として追加します。表情は1か所にしか入らないため、枠に入れた表情は **その他の表情** から外れます。
- 標準表情は連続値（isBinary なし）で、瞬き・口・視線は `blend` で抑えます。重み1では記録した表情と同じく瞬き・口・視線を止めます。
- 口（aa など）・瞬き・視線・neutral の標準表情は選べません。従来の自動設定のままです。

## 選べない項目

- **対応外**の表情は **その他の表情** に灰色で表示し、カードにマウスを重ねると理由を表示します。部分的な取り込みで欠落を隠さず、枠には入れられず、保存対象にも入りません。
- Playモード中は編集できません。
- 作者名が空欄または空白だけの場合は保存できず、作者名の欄の下に「VRMには作者名が必要です」と表示します。保存に使った作者名はアバターごとにこのPCのUnity Editorの設定に記録し、次に同じアバターを指定したときの初期値にします。記録の無いアバターでは欄の入力をそのまま使います。表情を追加しない通常のVRM保存もできます。

対応するのは書き出すSkinnedMeshRendererのBlendShapeです。材質・画像差し替え、顔ボーン、表示切替、Animation Event、曖昧なメッシュ統合や欠けた変形は未対応です。複数クリップの合成・共通FX設定が必要な顔は単一ファイルと異なる場合があります。
指定しない変形は毎回基準の顔から補い、直前の顔を引き継ぎません。最大64表情です。

顔の手動調整、メニュー全体の自動取り込み、コピー再作成、記録設定の保存・読み込みはこの画面に表示しません。瞬きの詳細は保存欄の**確認・調整**から別ウィンドウで開けます。自動で判定できない場合は**手動**で閉眼用のメッシュ・変形・適用量を指定し、プレビューして**設定を適用**します。既存VRMの口形・視線・瞬きなどの標準プリセットは保持します。アバターを再指定する場合は**変更**を使います。保存済みVRMは残ります。

## QR転送

PCで暗号化したVRMをクラウドへ一時保存します。復号鍵はQRだけに含め、サービスへ送りません。PCとiPhoneのインターネット接続が必要で、同じWi-Fiは不要です。256 MiB以下、受取期限は転送作成から3分です。アップロード中も期限が進みます。QRは共有・撮影しないでください。Android配布版の受信は無効です。

送信前に公式プライバシーポリシーへのリンクと同意チェックを表示します。同意はこのPCのUnity Editorに保存し、次回も選択状態を引き継ぎます。初回は未選択で、チェックを外すと新しい送信・QR再作成を開始できません。同意済みでもQR作成ボタンを押すまで送信しません。

転送は最後に保存したVRMを使います。編集した場合は再保存してください。保存ファイルの移動・上書きは検知して再保存を案内します。画面を閉じても元のVRMは消えません。通信エラーは停止した工程と原因を一度だけ表示します。
安定版0.11.15はbeta.2と同じQR転送モジュールを含みます。詳細は同梱の[QR転送ガイド](CloudTransfer.md)を参照してください。保存したVRMをファイルで端末へ転送する方法も利用できます。
