# lilToonの版ごとの見た目の違いを実物で比べた記録

- 日付: 2026-10-14
- 対象: `Compatibility/Evidence/LilToonVersionVisual/`（README・比較画像・数値・撮影と比較のスクリプト）
- 関連: Epic #145、子 Issue #150（WBS 1-10）、PR #166（#150 の文書更新）

## 背景

対応範囲を lilToon 2.0.0〜2.3.4 に広げ、Exporter は版ごとの値の変換をしない（#145）。アプリは 2.3.4 の決まりで描くので、古い版で作ったマテリアルは「その版の lilToon で作者が見ていた見た目」ではなく「2.3.4 へ上げた見た目」で表示される。Epic を立てた時点では、どの描画が変わるかはシェーダーのコードの差分から読んだだけで、同じマテリアルを各版で描いて比べていなかった。

## 決定

- 版ごとの空の Unity プロジェクト（2022.3.22f1・Built-in RP）で、その版の lilToon で合成のマテリアルを作って保存し、固定のカメラとライトで描く。続けて lilToon だけを 2.3.4 に差し替え、同じ `.mat` を描き直す。左右の画素の差を比べる。
- 撮るのは Skybox 付きで環境光を焼いたシーンにした。作者がエディタで開くシーンに近づけるため。保存していない空のシーン（ライトプローブの SH がゼロ）では 2.0.0 だけ陰影が消える（lilToon 2.1.0 の修正「Skybox が無効だと影が落ちない」）ので、これは別の条件として記録した。
- 公開リポジトリに載せる画像と数値は合成の素材だけにする。代表アバターは同じ手順で撮ったが、結果は文章だけにして、名前と画像は載せない。
- 撮影用の Editor スクリプトは `Capture.cs.txt` として置く。Exporter のチェックアウトは検証用プロジェクトから `file:` で参照されるので、`.cs` のままだと参照先のプロジェクトで読み込まれるおそれがある。
- 補正はしない（Epic の方針どおり）。

結果: 違いが出たのは、バックライトの色の A が 1 未満（全版・2.3.4 で暗くなる）、Outline Lit（2.0.0・2.1.0）、MatCap の UV1 が 0〜1 の外（2.0.0）の 3 つだった。代表アバターはこれらの機能を使っておらず、差は出なかった。

## 検討した代替案と不採用理由

- アプリ（Unity 6・URP）で表示して比べる: アプリは全版の書き出しを同じ 2.3.4 の決まりで描くので、アプリで見えるのは右の列にあたる。書き出したファイル自体が版によって変わらないことは #149 の照合で確かめる。今回は作者の見た目と 2.3.4 の見た目の違いを先に記録した。アプリでの表示は未実施として残す。
- 版ごとに別々の撮影シーンを作る: カメラ・ライト・環境の違いが混ざる。同じプロジェクトで lilToon だけを差し替える方が、差が lilToon の描画だけになる。
- 2.1.10・2.2.0・2.3.0・2.3.3 も撮る: 境目の版は 2.0.0／2.1.0／2.2.1 で挟めた。Outline Lit が 2.1.10 から画素単位になることはコード（`lil_common_frag.hlsl` の `outlineNdotL`）で確かめた。

## 影響

- Exporter のパッケージに入るファイルと書き出しの挙動は変わらない（`Compatibility/` はパッケージに入らない）。
- PR #166 の `Compatibility/README.md` の記述（バックライトの A・MatCap の UV1・Outline Lit の版）と結果は一致した。#166 は 2.0.0 の Skybox の件に触れていない。#166 の「影色の環境光の変更は強い環境光でだけ見える」は、ソースでは「lilToonLite で、主光源の色が 1 未満のとき」だった。

## 未決

- アプリ（Unity Editor・Android 実機）での表示の確認（#150 の 1-10 の残り）。
- 2.0.0 の Skybox の件を #166 の文書に書くか。作者がエディタで見ていた見た目だけの話で、書き出しには影響しない。
- 影色の環境光の変更（2.1.0）は、lilToonLite で環境光の混ぜ込みと明るい側への頭打ち（`min`）の順番が入れ替わったもの（通常の lilToon は効果の無い `saturate` が増えただけ）。光の色が 1 なら結果は同じで、今回の白色光 1.0 では差が出なかった。暗い・色の付いた主光源では lilToonLite の影が変わりうる。今回は試していない。
