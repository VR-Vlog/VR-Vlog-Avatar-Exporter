# 他者のアバター・衣装・商品・作者の名前を検出するスクリプトを置く

- 日付: 2026-10-19
- 対象: `Tools/check-names.py`・`CONTRIBUTING.md`

## 背景

オーナーが、このリポジトリに衣装名などを出さないよう指示した。動作確認には市販のアバターや衣装を使うので、Issue・PR・コミットメッセージに名前を書いてしまいやすい。

## 決定

- 名前の一覧はリポジトリの外に置き、コミットしない。一覧そのものが名前の公開になるため。
- `Tools/check-names.py` は一覧のパスを `--names` か環境変数 `EXPORTER_BANNED_NAMES` で受け取り、追跡中のファイル・任意のテキスト（Issue や PR の本文）・push される内容（ブランチ名・コミットメッセージ・追加行・ファイルパス）を調べる。
- 英数字だけの名前は単語単位・大文字小文字無視で照合し、それ以外は部分一致で照合する。一般的な英単語と同じ名前は誤検出が多いので一覧に入れない。
- 既定の出力は一覧の行番号だけにする。名前を表示するのは `--show` を付けたときだけ。
- 一覧が無いときは止めずに「確認しなかった」と出して終わる。一覧を持たない人の push を妨げないため。
- push のたびに確かめるには、各自がローカルの pre-push フックに登録する（手順は `CONTRIBUTING.md`）。

## 検討した代替案と不採用理由

- CI のジョブで検査する: 一覧をリポジトリかシークレットに置く必要があり、ログに名前が出るおそれもある。今回は入れず、必要になったら別に決める。
- 一覧をリポジトリに入れる: 一覧そのものが名前の公開になる。
