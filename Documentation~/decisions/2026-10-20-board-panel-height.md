# 表情ボードの下段の高さをドラッグで変えられるようにする

- 日付: 2026-10-20
- 対象: `Editor/ExperimentalExpressionCaptureWindow.cs`・`Tests/Editor/ExpressionSlotLayoutTests.cs`

## 背景

表情ボードの下段（**その他の表情** の格子と **書き出さない表情** の欄）は高さ 300 で固定だった。表情の多いアバターでは格子の中を何度もスクロールすることになるので、オーナーから高さを変えられるようにしてほしいと指示があった。

## 決定

- 2つの欄のすぐ下の 6 の隙間（これまで `EditorGUILayout.Space(6)` だった場所）をつまみにする。カーソルを乗せると上下のリサイズのカーソルになり、ドラッグで高さが変わる。つまみの中央に長さ 32・太さ 2 の横線を 1 本描く（ドラッグ中はアクセントの色）。Unity の標準の分割（Console・Animator など）はカーソルの変化だけだが、この画面では隙間がすぐ下の行やフッターの区切りに見えやすく、カーソルの変化だけでは気づきにくいため（デザインの相談で出た指摘を採った）。
- 高さは `EditorPrefs` の `VRVlog.ExpressionBoard.PanelHeight` に、ドラッグを離したときに保存する。既定は従来と同じ 300。
- 範囲は 160〜1000。160 は大きいサムネイルの 1 行が欄に収まる高さ。
- ページの表示範囲が欄より低いときは、欄の下端とつまみが表示範囲に収まる高さまで縮めて描く（`ShownPanelHeight`）。描くときだけ縮め、保存した値は変えないので、ドラッグしないまま窓を戻せば元の高さに戻る。小さい窓でドラッグしたときは、その窓に収まる高さを保存する（表示と保存の値をそろえるため）。ページ全体はこれまでどおりスクロールするので、窓を小さくしても上段の枠と下の行は操作できる。

## 採らなかった案

- 上段（13 枠）と下段の境目をつまみにする案: ボードはページ全体のスクロールの中にあり、上段の高さは枠の数で決まる。境目を上へドラッグしても上段は縮まず、下段の下端が下へ伸びるだけになり、指の動きと逆に見えるので採らなかった。
- UI Toolkit の `TwoPaneSplitView`: ウィンドウ全体が IMGUI で、ボードはページのスクロールの中に描いている。分割だけ UI Toolkit にすると描画の仕組みが 2 つに分かれるので採らなかった。
