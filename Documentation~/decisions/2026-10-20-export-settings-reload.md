# スクリプトの再読み込みや読めない設定ファイルで、保存済みの書き出し設定を消さない

- 日付: 2026-10-20
- 対象: `Editor/LilToonExporterWindow.cs`・`Editor/ExportSettingsStore.cs`・`Editor/Locales/*.json`・`Tests/Editor/ExportSettingsTests.cs`

## 背景

- `ExportSettings` はシリアライズしない型なので、スクリプトの再読み込み（再コンパイル・Play モードに入る）で窓の設定は既定値に戻る。選択中のアバターと保存済みの設定の要約（`savedSignature`）は Unity が残すので、次の `OnInspectorUpdate` で差分ありと判定し、既定値を保存してアバターの項目を消していた。
- 設定ファイルが壊れている・ほかのプロセスが開いている・4MB を超えるときは「ファイルが無い」と同じ扱いで、次の保存で新しいファイルに置き換え、ほかのアバターの設定と転送名を消していた。
- 瞬きの手動設定で、消えたメッシュを指す割り当てはメッシュが空のまま復元され、瞬きの確認で落ちて瞬き全体が書き出されなかった。

## 決定

- `savedSignature` と `loadedRevision` は再読み込みで残さない。`OnEnable` でアバターの設定を読み直し、読み直すまで（`savedSignature` が空のあいだ）は保存しない。見つからない対象の警告は、アバターを選んだときに出しているので、読み直しでは出さない。
- 設定ファイルがあるのに読めないときは、別の版のファイルと同じく警告を 1 回出して保存しない。警告にはファイルの場所と、直すか消せばまた保存できることを書く。空のファイルは消えて困る項目が無いので、従来どおり上書きする。
- 瞬きの割り当てのうち、保存時にメッシュを指していて今は見つからないものは、復元時に外して「見つからない対象」の件数に入れる。保存時にメッシュを指していなかった割り当ては残す。

## 確認したこと

- EditMode `ExportSettingsTests` 13/13（再読み込み後の状態で設定が残る・壊れた JSON とロック中のファイルを上書きしない・消えたメッシュの割り当てだけ外れる）。
