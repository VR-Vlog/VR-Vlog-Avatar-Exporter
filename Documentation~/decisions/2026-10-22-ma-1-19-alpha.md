# Modular Avatar 1.19.0-alpha.0〜alpha.2 は対応範囲に入れない

- 日付: 2026-10-22
- 対象: `Compatibility/dependencies.json`（変えない）・`Compatibility/README.md`

## 背景

表示の固定（`MaAppearanceSnapshot`）の対応範囲は 1.19.0 未満で、プレリリースは版を読めないものとして API を試す（2026-10-21-ma-unknown-version）。1.19.0 の公開ソース（タグ `1.19.0-alpha.0`〜`1.19.0-alpha.2`）を読み、Unity 2022.3.22f1 の実プロジェクトで確かめた。

- alpha.0 の解析結果は 1.18.7 と同じ形。alpha.1 で `InitialStates` が `Shapes`＋`InitialActions`（型つきの対象と最初から効いている動作）に変わった。1.18 の形に読み替えれば、表示の固定は 3 つとも動いた（AppearancePreparation 12/12・MaDeletionExport 6/6・NdmfPreparation 52/52）。
- alpha.1 と alpha.2 は NDMF 1.15.0-beta.1 以上を要求する。今の NDMF の橋渡しは `-` を含む版を止めるので、この 2 つはそもそも書き出せない。
- MaReactiveExpressionExport は alpha.0・alpha.1 で 3/15、alpha.2 で 9/15 しか通らなかった（1.18.7 は同じ手順で 15/15）。
  - MA 1.19 は FX を BlendTree で作り、メニューのパラメーターが Animator では Float になる。表情メニューの取り込み（`PoseMenuResolver`）が「Expression ParametersとAnimatorパラメーターの型が一致しません」で止まり、メニューの表情が 1.18 と同じに書き出されない（3 つとも）。
  - alpha.0・alpha.1 では、MA 自身のビルドでも Merge Motion の非メニューの起動が 1.18 と違う値になる（Smile が 100 でなく 25）。

## 決定

- 1.19.0-alpha.0〜alpha.2 は対応範囲に入れない。`modularAvatarBelow` は 1.19.0 のまま、プレリリースの一覧も足さない。
- alpha.1 の解析結果の読み替えと NDMF のベータを通す変更は取り込まない。
- メニューの取り込みを MA 1.19 の FX に合わせる作業は、1.19.0 の正式版が出てから行う。

## 理由

- 表示の固定が動いても、メニューの表情が 1.18 と同じに書き出せなければ、利用者には書き出しの結果が変わったように見える。
- alpha の間は FX の作りがまた変わり得る。BlendTree の評価を取り込みに足す作業（見込み 2 日）は、正式版の形が決まってからの方が手戻りが無い。

## 残ること

- 今のプレリリースの扱い（版を読めないものとして試す）では、alpha.0 は固定まで進み、メニューの表情は警告つきで書き出される。プレリリースを固定の前に止める変更は別に検討する。
