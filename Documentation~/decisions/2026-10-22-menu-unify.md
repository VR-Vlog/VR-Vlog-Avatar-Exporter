# 右クリックとメニューバーの VR Vlog を同じ 3 項目にそろえる

- 日付: 2026-10-22
- 対象: `Editor/Compatibility/ExporterMenu.cs`・`Editor/Compatibility/DependencyDiagnostics.cs`・`Editor/LanTransfer/AppTransferWindow.cs`・`Editor/AppPreviewWindow.cs`・`Editor/ExperimentalExpressionCaptureWindow.cs`

## 背景

Hierarchy の右クリックの **VR Vlog** には **アプリに転送（かんたん）**・**アプリに転送（通常）** の 2 つ、上のメニューバーの **VR Vlog** には **VRMを書き出す**・**アプリでの見え方を確認** の 2 つがあり、同じ名前のメニューなのに中身が違っていた。転送はメニューバーから、書き出しは右クリックから選べなかった。メニューの案をいくつか並べ、10/22 に mk が M1 を選んだ。

## 決定

右クリックとメニューバーの **VR Vlog** に、同じ 3 項目を同じ順で並べる。

1. **アプリに転送（かんたん）...**
2. **アプリに転送（通常）...**
3. 区切り線
4. **VRMを書き出す...**

- 項目名の末尾に「...」を付ける。どれも選ぶと設定の画面が開き、すぐには書き出さないため。メニューの文言はこれまでどおり翻訳しない。ショートカットキーは付けていない（もとから無い）。
- 優先度は、メニューバーが 1000・1001・1012、右クリックが 10000・10001・10012。Unity は優先度の差が 10 より大きいところに区切り線を入れるので、転送の 2 つと書き出しの間に区切り線が入る。右クリックの 10000 は 2026-10-21 の決定記録のまま、メニューバーの 1000 はもとの **VRMを書き出す** の値。値は `ExporterMenu` に 1 か所で置き、転送のモジュールと書き出しの両方がそこから読む。
- 右クリックの項目はクリックしたアバター、メニューバーの転送の 2 つは Hierarchy で選んでいるアバターを対象にする。アバターの一番上のオブジェクト（Animator を持つルート）を 1 つだけ選んでいないときは灰色にする。転送の 2 つは、クラウド転送が無効な版では出さないか灰色のまま。
- メニューバーの **VRMを書き出す...** は今までどおり常に選べて、アバターを指定しないで書き出し画面を開く。パッケージが足りないときは対策画面を開く。
- 右クリックの **VRMを書き出す...** は、書き出し画面をそのアバターを指定した状態で開く。**書き出しを準備** は押さない（準備は重く、ほかのアバターを選び直すこともあるため）。準備済みの画面では、画面の **変更** ボタンと同じ確認を出してから切り替える。パッケージが足りないときは対策画面を開く。
- 表情ボードが **アプリに転送（通常）** の3ページ目でアップロード中かQRの表示中なら、どちらの **VRMを書き出す...** も先に「転送を中止」の確認を出す。**戻る** を選ぶと、転送もアバターもそのままにする（`ChooseForExport`）。
- 書き出しのメニューは、常にコンパイルされる Compatibility のアセンブリに置く。書き出し画面のアセンブリはパッケージが足りないとコンパイルされないので、`DependencyDiagnostics` がリフレクションで `ExperimentalExpressionCaptureWindow.OpenFor` を探して呼ぶ。見つからないときは、アバターを指定しない書き出し画面を開く。
- メニューの **VR Vlog → アプリでの見え方を確認** は外す。**アプリでの見え方** の画面は、VRM を保存したあとの **アプリでの見え方を確認** ボタンからだけ開く。保存済みの任意の `.vrm` をメニューから開く入口は無くなる。開いた画面の **VRM ファイルを開く** で別のファイルは選べる。
- アプリに転送（かんたん）の書き出す中身は変えない（`QuickTransferMatchesDefaultNormalTests`）。

## Codex の意見から入れたもの

- 対象のアバターが選ばれていないときに項目を灰色にすること。
- 転送と書き出しの間の区切り線。
- 画面が開く項目の末尾の「...」。

## 入れなかったもの

- **アプリに転送（通常）** の「通常」の言い換え。項目名は mk が決めたものを使う。
- **アプリでの見え方を確認** をメニューに残すこと。mk が選んだ M1 はこの項目を外す案だった。

## 確認したこと

- パスと優先度が変わったので、EditMode テスト（`CloudTransferWindowTests`・`DependencyStartupTests`・`AppPreviewWindowTests`）と起動確認の `Tests/Startup/ExporterStartupProbe.cs` を新しいパスに直した。`AppPreviewWindowTests` のメニューのテストは、メニューを外したので消した。
- 新しい EditMode テスト `VrVlogMenuTests`（両方のメニューが同じ 3 項目・同じ順・区切り線、アプリでの見え方のメニューが無いこと、アバターのルートを 1 つだけ選んでいないときは灰色）と `VrVlogMenuExportTests`（右クリックの書き出しがそのアバターを指定して開くこと、メニューバーの書き出しはアバター無しで開くこと）を足した。
- 検証環境の Unity 2022.3.22f1 で、メニューバー・右クリック・何も選んでいないときのメニューバーを撮り、変更前と並べた（`Documentation~/Verification/menu-unify-*.png`）。
