# 遷移し直し続けるレイヤーがあっても、ジェスチャーの表情全体を捨てない

- 日付: 2026-10-22
- 対象: `Editor/VrChatExpressionSampler.cs`（`ValidateFixedPose`）・`Editor/ExpressionSettlement.cs`・`Editor/ExpressionEvaluationSession.cs`・`Editor/ExpressionDependencies.cs`・`Tests/Editor/ExpressionSettlementTests.cs`

## 背景

FX の中に、Any State から状態への遷移で `Can Transition To Self` が有効・終了時間なし・条件が真のまま（`GestureLeft = 0` や「AFK でない」など）のものがあることがある。小物の表示切り替えや待機状態のレイヤーでよく見る作り方。

この遷移は、遷移が終わるたびに同じ状態へもう一度始まる。そのためレイヤーは「同じ状態から同じ状態への遷移中」のまま止まらない。無料アバターの一部では、このレイヤーがあるだけでジェスチャーの表情がすべて拒否され、表情が 1 つも取り込めなかった。

## 原因

同じ状態を、処理によって受け付けたり拒否したりしていた。

- `ExpressionSettlement` は、同じ状態へ戻る遷移を許す規則（`SelfTransition` の警告）を持っている。一方で、遷移の終わりを待つべき事象として扱っていたので、終わらない遷移を待ち続け「時間遷移を最後までたどれない」で拒否していた。
- `ValidateFixedPose` は、遷移中のレイヤーを一律に「FXの状態遷移が静止していません」で拒否していた。

レイヤーが遷移し直しても、出ている状態は同じで、Clip も同じ時刻から再生されるだけなので、表情の値は変わらない。変わりうるのは、状態に入るたびに走るコールバック（Parameter Driver など）だけである。

## 決定

Unity の Animator の定義から、遷移し直しても何も変わらない場合だけを受け付ける。

- **Settlement**: 現在の状態へ入る Any State の遷移で、`canTransitionToSelf`・ミュートでない・`hasExitTime` なし・条件がすべて今の値で真のものがあれば、その遷移の終わりは待たない。条件に Trigger を含む遷移は、遷移し直すときに Trigger を消費して止まるので除く。
- **ValidateFixedPose**: 次の状態が今の状態と同じ遷移は、静止した状態と同じ検査（Clip の時刻・コールバック）を通れば受け付ける。
- **コールバック**: 遷移し直すたびに、その状態と親のステートマシンのコールバックがもう一度走る。もう一度走っても何も変えないものだけを許す。
  - Tracking Control は同じモードをもう一度設定するだけなので許す。
  - Parameter Driver とレイヤーの重みの制御は、評価用の Controller で実行するときと同じ処理（`ExpressionEvaluationSession.Run`）を、書き込まずに走らせて、パラメーター・重み・FX の状態のどれかが変わるかで決める。評価できない操作（Random など）は変わるものとして扱う。
  - それ以外のコールバックは変わるものとして扱う。

## 成り立たない場合

次の場合はこれまでどおり拒否する。

- 遷移し直すたびに値を変える Parameter Driver（Add、今の値と違う値への Set、Copy 元が動くもの）。
- Random を含む Driver。値が決まらないので変わるものとして扱う。
- 遷移し直すたびに FX の重みを変える Playable Layer Control。
- 条件に Trigger を含む遷移、終了時間で戻る遷移。どちらも遷移し直し続けるとは限らない。
- 別の状態へ移っていく遷移。これは今回の変更の対象ではない。

特定のアバター・Clip 名・パラメーター名に合わせた分岐やしきい値は入れていない。

## 確認したこと

- EditMode テスト（Settlement・メニューとジェスチャーの表情・FX の探索・顔の形状評価まわりの 473 件）がすべて通った。追加したテストは、遷移し直し続けるレイヤーがあっても表情を保つこと（同じレイヤー・別レイヤーの両方）、値を変え続ける Driver があれば拒否すること、Tracking Control と今の値を設定し直すだけの Driver なら保つことを確かめる。
- 無料アバターのうち、この仕組みで拒否されていた 3 体を書き出し直し、3 体ともジェスチャーの表情が取り込まれた（13〜15 個）。
