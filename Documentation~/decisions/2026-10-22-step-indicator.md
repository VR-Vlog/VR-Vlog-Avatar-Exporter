# 表情ボードの手順の行を丸と線にする

- 日付: 2026-10-22
- 対象: `Editor/StepIndicator.cs`・`Editor/ExperimentalExpressionCaptureWindow.cs`・`Tests/Editor/StepIndicatorTests.cs`

## 背景

表情ボードの上の手順の行は「1 表情の設定 › 2 除外するオブジェクト › 3 VRMの情報」を1行の文字で並べ、今のページを太字、まだのページを薄い色にしていた。文字の太さと濃さだけで区別するので、どこまで済んだかが一目で分かりにくかった。2ページ目の除外がプレビューに反映できなかったときも、行には何も出ていなかった。

手順の行の案を4つ作って画面で比べ、mk が 10/22 に A（番号の丸を線でつなぐ案）を選んだ。

## 決定

- 手順ごとに直径20pxの丸を置き、その右に手順の名前を出す。丸と丸の間は1pxの線でつなぐ。線の色は枠線と同じ中間色（`CardBorderColor`）。
- 丸の表し方は次のとおり。
  - 済んだ手順: アクセントの青で塗った丸に白のチェック。番号は出さない。名前は通常の色。
  - 今の手順: アクセントの青で塗った丸に白の番号。名前は太字。
  - まだの手順: 薄い色の輪に薄い色の番号。名前も薄い色。
  - 2ページ目の除外がプレビューに反映できなかったとき（`excludedObjectError`）: 2の丸を赤で塗って「!」を出し、名前を赤にする。2ページ目が今のページなら名前は太字のまま赤にする。
- 済んだ手順は番号の代わりにチェックを出す。名前は残るので、並び順から何番目かは分かる。20pxの丸に番号とチェックを両方入れると詰まって読みにくい。よく使われるステッパーも済んだ手順はチェックだけを出す。
- 名前の文字列は今までと同じ「1 表情の設定」などを使い、先頭の番号を丸に、残りを名前に分けて出す。転送のときの3は「3 名前と利用条件」のまま。新しい文言は足していない。
- 準備の前（`session` が無いとき）は1を今の手順として出す。手順の行は押せないまま（移動は下のバーの **戻る** と **次へ** だけ）。
- 色は中間色・アクセントの青・エラーの赤の3つだけを使う。グラデーションと左端の色の帯は使わない。

### 幅の配り方

位置と幅は行の幅だけから決め、文字の大きさや名前の長さは使わない（`StepIndicator.Compute`）。

1. 丸は3つとも20px、丸と名前の間は8px。線の両端には10pxずつ空ける。
2. 名前の枠の合計は、行の幅から丸と、いちばん短い線（16px）とその余白を引いた残り。ただし420pxを上限にする。
3. 名前の枠は合計を 0.8 : 1.1 : 1.1 で分ける。1の「表情の設定」はどの言語でもいちばん短く、2と3が長い（英語の「Objects to exclude」「Name and usage terms」）。
4. 残りは2本の線に等しく配る。ウィンドウを広げると線が伸び、名前の枠は広がらない。

ウィンドウの最小幅600（行の幅568）では名前の枠が109・151・151px、線が16pxになる。既定の幅1000（行の幅968）では名前の枠が112・154・154px、線が212pxになる。枠に入らない名前は末尾を「…」で切り、ツールチップに番号つきの名前を全部出す。

### 文字の大きさで配置が変わらないこと

丸・線・名前の枠の位置は行の幅だけで決まるので、エディタの文字を大きくしても動かない。大きくした文字が枠に入らなければ「…」で切れるだけで、隣の丸や線は動かない。行の高さは20pxから24pxにした（固定のまま）。行の下の余白は8pxから12pxにした。

## 相談した意見

案Aの描き方について別のモデルに意見を求めた。

採ったもの:

- 丸をつなぐ線は1pxの中間色にする。
- 丸は20pxにする。
- 2ページ目にエラーがあっても、そこが今の手順なら名前の太字を残す。赤だけにすると、今どのページにいるかが行から読めなくなる。

採らなかったもの:

- 済んだ手順を押して戻れるようにする。今までどおり移動は **戻る** と **次へ** だけにした。

## 入れなかったもの

- 比べた残りの案（B: エディタの切り替えボタンを3等分で並べる、C: 今の手順の名前と「2/3」の下に3分割のバーを出す、D: 左に手順の列を置く）。比べるために作ったもので、残していない。
- 転送のときの3ページ目（名前と利用条件を表情ボードの中に出す）。別の変更で扱う。

## 確認したこと

- EditMode テスト `StepIndicatorTests` を足した。各ページで済んだ・今・まだの手順が正しいこと、準備の前は1が今の手順になること、エラーは2だけに出て今の手順の太字が残ること、転送のときに3の名前が変わること、行の幅568・968・1400で名前の枠と丸と最短の線が行に収まること、ウィンドウの中でエディタの文字を大きくしても丸・名前の枠・線の位置が変わらないことを確かめる。
- 変更前と変更後の画面を、幅1000と600で、各ページと2ページ目のエラーについて撮って比べた（`Documentation~/Verification/step-indicator-*.png`）。幅600で日本語・英語・韓国語・簡体字・繁体字の画面を撮り、名前が枠からはみ出さないことを確かめた。
