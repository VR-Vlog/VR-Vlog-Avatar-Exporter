# ポーズの仕組みを探すとき、体に結び付いた根の中のコンポーネントを読まない

- 日付: 2026-10-23
- 対象: `Editor/ExportGimmickDetection.cs`（`PoseTools`）

## 背景

ポーズの仕組みを働きで見分ける処理（2026-10-23-pose-tool-exclusion）は、アバターの下のすべての MonoBehaviour について、参照しているアニメーションが胴や脚を動かすかを調べる。調べる処理はコンポーネントのシリアライズされた値をすべてたどるので重い。そのあとで「仕組みの根」が体に結び付いている（ボーンを使うSkinned Mesh RendererかMerge Armatureなどを含む）かを調べ、結び付いていれば外さない。

衣装の根の下には MonoBehaviour が多いが、どれも結び付きの確認で外れるので、アニメーションを調べた分が無駄になっていた。結び付きの確認も、同じ根の下のコンポーネントごとに根の子をすべて取り直していた。

## 決定

- 結び付きの確認を根ごとに1回だけ行って覚えておき、アニメーションを調べる前に行う。
- 見つかるものは変わらない。どちらの確認も外すかどうかを決めるだけで、順番を入れ替えても結果は同じになる。

## 確認

- 既存の `ExportGimmickTests` が Unity 2022.3 で通ることを確かめた。
