# 1.0.0以降の修正と機能を安定版1.1.0として公開する

- 日付: 2026-10-23
- 対象: `package.json`・`Editor/LilToonExporterWindow.cs`（`PackageVersion` のフォールバック）・`CHANGELOG.md`・`README.md`・`README.en.md`・`Documentation~`・`Compatibility/AvatarPreservation.md`

## 背景

1.0.0の公開後、developにはトゥーンシェーダーの透過の読み替え（#473）、ハンドジェスチャーの表情（#444）、Parent Constraintの小物の付け替え（#466）、転送後の画面の変換の内容（#459）、Boundsの誤差での誤判定の修正（#475）、診断情報のコピー（#474）などが入った。ALCOMの通常の一覧から使う人にこれらを届ける。

## 決定

- 後方互換の機能追加を含むので、版はMINORを上げて `1.1.0` にする。
- 1.0.0と同じく `release/1.1.0` からmainへMerge commitで昇格し、候補の生成後に **Release VPM Packages** をmainから `channel=stable` で起動する。リリースノートは `CHANGELOG.md` の `## 1.1.0` の節がそのまま使われるので、そこを7行以内の要約にし、各項目の詳細は「1.1.0の詳細」に置く。
- QR転送は2026-10-23-qr-transfer-stable-from-1.0.mdの規則で1.1.0にも入るので、版の名指しは足さない。
- 文書の「現在の安定版」の記述を1.1.0にし、1.0.0から変わらない範囲の記述（lilToonのバージョンを問わない・VRMの確認画面の入口が無い）は「1.0.0以降」にした。
- 開いたままの #440 は入れない。
