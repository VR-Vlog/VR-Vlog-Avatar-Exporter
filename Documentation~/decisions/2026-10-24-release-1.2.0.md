# 1.1.0以降の機能と修正を安定版1.2.0として公開する

- 日付: 2026-10-24
- 対象: `package.json`・`Editor/LilToonExporterWindow.cs`（`PackageVersion` のフォールバック）・`CHANGELOG.md`・`README.md`・`README.en.md`・`Documentation~`・`Compatibility/AvatarPreservation.md`

## 背景

1.1.0の公開後、developにはExpression Menuのトグルで切り替えるオブジェクトの書き出し（#440）、負のスケールで反転させた小物の向きの修正（#478）、逆光ライトのアルファの修正（#480）、リムライトと併用したマットキャップのマスクの修正（#483）、Modular Avatarの取り付け先が見つからないときの警告（#482）が入った。ALCOMの通常の一覧から使う人にこれらを届ける。

## 決定

- 後方互換の機能追加（#440）を含むので、版はMINORを上げて `1.2.0` にする。
- 1.1.0と同じく `release/1.2.0` からmainへMerge commitで昇格し、候補の生成後に **Release VPM Packages** をmainから `channel=stable` で起動する。リリースノートは `CHANGELOG.md` の `## 1.2.0` の節がそのまま使われるので、そこを7行以内の要約にし、各項目の詳細は「1.2.0の詳細」に置く。
- #440は対応版より前のアプリで既定で非表示のオブジェクトも表示されるので、要約の行にその条件を書く。
- CHANGELOGに無かった#482・#483の項目を「1.2.0の詳細」に足した。
- 文書の「現在の安定版」の記述を1.2.0にした。
