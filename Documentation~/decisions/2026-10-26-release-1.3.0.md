# 1.2.0以降の機能と修正を安定版1.3.0として公開する

- 日付: 2026-10-26
- 対象: `package.json`・`Editor/LilToonExporterWindow.cs`（`PackageVersion` のフォールバック）・`CHANGELOG.md`・`README.md`・`README.en.md`・`Documentation~`・`Compatibility/AvatarPreservation.md`

## 背景

1.2.0の公開後、developには **アプリに転送（かんたん）** のプレビュー（#499・#500・#501）、Lip SyncがViseme Parameter Onlyのアバターの口の動きの書き出し（#504）、喜怒哀楽の名前の語の追加（#488・#489）、診断情報の「書き出さなかったギミック」の節と名前つきのコピー（#492・#493）、待機中の顔と口の形の修正（#490・#502）、Lockがオフのコンストレイントと親が違う回転コンストレイントの変換（#486・#506）、表情ボードで書き出せなくなった.animの表示（#507）が入った。ALCOMの通常の一覧から使う人にこれらを届ける。

## 決定

- 後方互換の機能追加（#499・#504）を含むので、版はMINORを上げて `1.3.0` にする。
- 1.2.0と同じく `release/1.3.0` からmainへMerge commitで昇格し、候補の生成後に **Release VPM Packages** をmainから `channel=stable` で起動する。リリースノートは `CHANGELOG.md` の `## 1.3.0` の節がそのまま使われるので、そこを7行以内の要約にし、各項目の詳細は「1.3.0の詳細」に置く。
- mainにだけあった公式サイトの計測スクリプトの追加（#481）は、release/1.3.0にmainを取り込んで含める。
- #504の口の動きは対応版より前のアプリでは使われないので、要約の行にその条件を書く。
- CHANGELOGに無かった#506の項目を「1.3.0の詳細」に足した。
- `Compatibility/AvatarPreservation.md` の「未リリースの次の版から」を「安定版1.3.0から」にし、文書の「現在の安定版」の記述を1.3.0にした。
- リリースノートに画像は付けない。プレビューの画面にはアバターが写り、公開リポジトリにはツールのUI以外の画像を載せない決まりのため（1.0.0〜1.2.0も画像なし）。
