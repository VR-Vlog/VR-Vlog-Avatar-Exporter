# 最適化系のツールで表情が消える修正を安定版1.3.3として公開する

- 日付: 2026-10-29
- 対象: `package.json`・`Editor/LilToonExporterWindow.cs`（`PackageVersion` のフォールバック）・`CHANGELOG.md`・`README.md`・`README.en.md`・`Documentation~`・`Compatibility/AvatarPreservation.md`

## 背景

1.3.2までは、最適化系の非破壊ツールを入れたアバターで、表情ボードのプレビュー用のコピーがNDMFのOptimizingまで走っていた。ツールがシェイプキーの名前を変えたりまとめたりすると、ボードの項目が黙って外れ、書き出す表情がほとんど消えていた。Optimizingのパスがエラーを出すアバターでは、ボードを作れずにアプリに転送（かんたん）がVRMを書かずに失敗していた（2026-10-29-board-preview-before-optimizing）。#523でdevelopを直したので、ALCOMの通常の一覧から使う人に届ける。1.3.2以降のdevelopには、ほかに1.3.2のmainの取り込み（#522）だけが入っている。

## 決定

- 不具合の修正だけで機能の追加がないので、版はPATCHを上げて `1.3.3` にする。
- 1.3.2と同じく `release/1.3.3` からmainへMerge commitで昇格し、候補の生成後に **Release VPM Packages** をmainから `channel=stable` で起動する。リリースノートは `CHANGELOG.md` の `## 1.3.3` の節で、7行以内にする。
- 文書の「現在の安定版」の記述を1.3.3にする。
- リリースノートに画像は付けない（1.0.0〜1.3.2と同じ）。

## 確認

- #523: VRChat SDK・Modular Avatar・NDMF入りのプロジェクトでEditModeテストを全体で回し、developでも落ちる同じテスト以外に落ちたテストはなく、追加したテストは成功した。追加したテストは、修正を外すと落ちることも確かめた。
- 手元の実アバター7体と公開版のツールで、ツールの有無と設定の組み合わせを書き出し、修正後は表情の数・シェイプキー・マテリアルの数と、表情ごとの頂点の移動量の合計・動く頂点の数が、ツールなしで書き出したものと一致した。
