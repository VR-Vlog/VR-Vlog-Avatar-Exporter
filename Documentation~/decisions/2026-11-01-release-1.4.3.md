# 1.4.2以降の修正を安定版1.4.3として公開する

- 日付: 2026-11-01
- 対象: `package.json`・`Editor/LilToonExporterWindow.cs`（`PackageVersion` のフォールバック）・`CHANGELOG.md`・`README.md`・`README.en.md`・`Documentation~`・`Compatibility/AvatarPreservation.md`

## 背景

1.4.1のあと、developに#546（表情のボーンと表示の切り替えの書き出し）・#552・#553・#555・#558・#559が入った。1.4.2はmainへのhotfixとして公開し、developへは戻していなかった（転送の修正#537はdevelopに同じ内容で入っている）。

## 決定

- 依頼者の指示でPATCHを上げて `1.4.3` にする。#546は機能の追加（`enhancement`）だが、既存の書き出し形式を壊さないので、今回はMINORにしない。
- `release/1.4.3` はdevelopの `b296aa3f`（#559のマージ）から作る。これより後にdevelopへ入るものは含めない。
- 1.4.2のmainを `release/1.4.3` へ先にマージする。衝突は `CHANGELOG.md` と `Documentation~/CloudTransfer.md` の規約の記述だけで、後者は公開済みのmain側を採る。
- developの `## 未リリース` の節は、リリースノートになる `## 1.4.3` の節（7行以内）に書き直す。各変更の詳しい説明は各PRと決定記録に残っている。
- `PackageVersion` のフォールバックは1.4.2では変えなかった（hotfixでUIのソースを変えないため）が、developからの通常の昇格なので1.4.1までと同じく版に揃える。
- 1.4.1と同じく `release/1.4.3` からmainへMerge commitで昇格し、候補の生成後に **Release VPM Packages** をmainから `channel=stable` で起動する。リリースノートに画像は付けない。

## 確認

- release ZIPをUnity 2022.3の新しいプロジェクトに入れて起動し、合成アバターを書き出せることを確かめた結果はこの版のPR本文に書く。
