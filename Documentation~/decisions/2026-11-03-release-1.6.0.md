# 片目ずつの瞬きを、マイナーの安定版1.6.0として公開する

- 日付: 2026-11-03
- 対象: `package.json`・`Editor/ExportEntry.cs`（`PackageVersion` のフォールバック）・`CHANGELOG.md`・`README.md`・`README.en.md`・`Documentation~`・`Compatibility/AvatarPreservation.md`

## 背景

1.5.4のあと、developに#569（VRCFuryの前にNDMFの生成物を保存する）・#571（マテリアルが空のスロット）・#595（動く表情を顔を保つ区間で焼く）・#603（表情ボードの作り直しでまばたきとポーズの画面を閉じない）・#604（訳した注記のテスト）・#605（英訳の直し）・#640（大規模リファクタリング）・#643（保守側に倒した理由を警告に出す）・#636（片目ずつの瞬き）が入った。

## 決定

- 前回のリリースから機能の追加があればMINORという依頼者の決まりに従い、#636が機能の追加なのでMINORを上げて `1.6.0` にする。
- `release/1.6.0` はdevelopの `bb4b757b`（#636のマージ）から作る。1.5.4のmainは#639でdevelopへ戻してあるので、mainの取り込みは要らない。
- `PackageVersion` のフォールバックは、#640で `LilToonExporterWindow` から `ExportEntry` へ移ったので、そちらを書き換える。
- #571の変更履歴は、developへのマージで公開済みの `## 1.5.0` の節に入っていた。1.5.0には含まれていないので、そこから消し、`## 1.6.0` の節に書く。
- `## 1.6.0` の節は利用者に見える変更だけを7行以内で書く。#604・#640・#643は通常の書き出しのVRMの中身と画面を変えない（#643は読み取りに失敗したときだけ警告が1行増える）ので書かない。
- 版を書き換えるファイルと公開の手順は1.5.4と同じにする（[1.5.4の決定記録](2026-11-03-release-1.5.4.md)）。
