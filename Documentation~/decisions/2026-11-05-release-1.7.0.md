# 揺れものと表情ボードの瞬きの変更を、マイナーの安定版1.7.0として公開する

- 日付: 2026-11-05
- 対象: `package.json`・`Editor/ExportEntry.cs`（`PackageVersion` のフォールバック）・`CHANGELOG.md`・`README.md`・`README.en.md`・`Documentation~`・`Compatibility/AvatarPreservation.md`

## 背景

1.6.0のあと、developに#644（Formatsの検査）・#647（揺れものの換算）・#650（テストの削減）・#651（16MBを超える動くポーズ）・#652（HumanoidのボーンをSpringBoneに入れない）・#653（Inside Boundsのコライダー）・#654（カメラ視線のシェイプキー）・#655（メニュー名の併記）・#656（回帰テストの表）・#657（restをTポーズにそろえる）・#660（人型でないアバターの瞬きの欄のエラー）・#662（瞬きのスイッチをなくす）・#663（リリース確認スクリプト）が入った。

## 決定

- 依頼者の指示でMINORを上げて `1.7.0` にする。
- `release/1.7.0` はdevelopの `66f37f69`（#662のマージ）から作り、そのあと入った#660と#663を `3c910ca7` で取り込む。1.6.0のmainは#646でdevelopへ戻してあるので、mainの取り込みは要らない。
- develop の `## 未リリース` の節は `## 1.7.0` にまとめる。`## 1.7.0` の節は利用者に見える変更だけを7行以内で書く。#644・#650・#656・#663は書き出すVRMの中身と画面を変えないので書かない。#653は#647と同じ揺れものの項目に含める。
- 版を書き換えるファイルと公開の手順は1.6.0と同じにする（[1.6.0の決定記録](2026-11-03-release-1.6.0.md)）。
