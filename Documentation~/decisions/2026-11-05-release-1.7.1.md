# NonToonのテクスチャの修正を、パッチの安定版1.7.1として公開する

- 日付: 2026-11-05
- 対象: `package.json`・`Editor/ExportEntry.cs`（`PackageVersion` のフォールバック）・`CHANGELOG.md`・`README.md`・`README.en.md`・`Documentation~`・`Compatibility/AvatarPreservation.md`

## 背景

1.7.0のあと、developに#665（1.7.0のmainの取り込み）・#666（回帰テストの表の検査）・#667（Insideカプセルのコライダー）・#668（コンストレイントとHumanoidのボーン）・#669（AAOのテスト素材と視線の統合）・#670（NonToonなどのテクスチャ）・#671（Poiyomi Toonの影色）が入った。

## 決定

- 依頼者の指示でPATCHを上げて `1.7.1` にする。
- `release/1.7.1` はdevelopの `bdaccb29`（#670のマージ）から作る。1.7.0のmainは#665でdevelopへ戻してあるので、mainの取り込みは要らない。
- developの `## 未リリース` の節は `## 1.7.1` にまとめ、NonToonの修正を先頭に書く。
- リリースには比較画像を添付しない。公開リポジトリにスクリーンショットを載せない決まりがあり、画像にはアバターが写るため。
- 版を書き換えるファイルと公開の手順は1.7.0と同じにする（[1.7.0の決定記録](2026-11-05-release-1.7.0.md)）。
