# lilToon以外のシェーダーの近似を、マイナーの安定版1.8.0として公開する

- 日付: 2026-11-05
- 対象: `package.json`・`Editor/ExportEntry.cs`（`PackageVersion` のフォールバック）・`CHANGELOG.md`・`README.md`・`README.en.md`・`Documentation~`・`Compatibility/AvatarPreservation.md`

## 背景

1.7.1のあと、developに#675（1.7.1のmainの取り込み）・#673（Sunao Shader）・#674（Unity-chan Toon Shader）・#676（Silent's Cel Shading）・#677（前提のパッケージが無いプロジェクトのテスト）・#678（UnlitWF）・#679（Arktoon）・#680（Gammaのプロジェクトの焼き込みの色）・#681（Mochie Standard）・#682（Xiexe XSToon）・#683（orels Toon）が入った。

## 決定

- 前回のタグ（`v1.7.1`）からenhancementのPRが8本（#673・#674・#676・#678・#679・#681・#682・#683）入ったので、MINORを上げて `1.8.0` にする。
- `release/1.8.0` はdevelopの `62d0e8a7`（#683のマージ）から作る。1.7.1のmainは#675でdevelopへ戻してあるので、mainの取り込みは要らない。
- developの `## 未リリース` の節は `## 1.8.0` にまとめ、利用者に見える変更だけを7行以内で書く。8つのシェーダーの近似は1項目にまとめ、#681に含まれていた画面を取り込むパスのエラーの修正と#680は別の項目にする。#677はテストだけの変更なので書かない。
- リリースには画像を添付しない。公開リポジトリにスクリーンショットを載せない決まりがあり、比較画像にはアバターが写るため。
- 版を書き換えるファイルと公開の手順は1.7.1と同じにする（[1.7.1の決定記録](2026-11-05-release-1.7.1.md)）。
