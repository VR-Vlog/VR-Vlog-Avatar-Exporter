# 書き出すVRMの確認で、見た目の変更を全件開けるようにし、案内先の無い文を外す

- 日付: 2026-11-07
- 対象: `Editor/ExportAppearanceReport.cs`・`Editor/ExportRecoveryComparisonWindow.cs`・`Editor/Locales/*.json`

## 背景

「書き出すVRMを確認」のウィンドウは、見た目の変更を HelpBox に 3 件まで並べ、4 件以上なら「ほか N 件。詳細から確認できます。」と出していた。このウィンドウには「詳細」というボタンも画面も無いので、案内先が無かった。句点と「できます」も UI 文言の決まりに合わない（#696 で見つけた）。

また、日本語以外の Editor でも日本語のまま出る文が 4 つあった。`ExporterLocalization.T` に渡しているが、ロケールの表に項目が無かった（表情クリップの適用元を確定できないとき、Random を使う待機表情・待機アニメーションを止めたとき、自動まばたきとリップシンクの FX を止めたとき）。

## 決定

- 4 件以上のときは HelpBox の末尾を「ほか{0}件」（表にある既存の文）にし、HelpBox の下に Foldout「すべて表示」を置く。開くと HelpBox に全件を並べ、「ほか N件」は出さない。Foldout のラベルは開閉で変えない（開閉は三角の向きで分かる）。
- 使わなくなった「\nほか 」「 件。詳細から確認できます。」の 2 項目を 4 言語の表から外し、「すべて表示」と上の 4 つの文を足した。訳語は表にある同じ語（書き出し用コピー・表情クリップ・まばたき・Random など）に合わせた。

## 検討した代替案と不採用理由

- 「ほか N件」だけにして、全件を見る手段を足さない: 保存する前に見た目の変更を確かめる画面なので、隠れた変更を見られないのは困る。
- Foldout のラベルを「ほか N件」にする: 開いたあとに何の件数かが分かりにくくなる（Codex の指摘）。
- 最初から全件を並べる: 変更が多いアバターでは、プレビューと保存のボタンが下へ押し出される。

## 確かめたこと

- 表に項目の無い `T()`・`Format()` の文字列を、ソースから機械的に洗い出して 0 件になることを確かめた。
- `Tools/validate.py`（ロケールの検査を含む）が通った。
