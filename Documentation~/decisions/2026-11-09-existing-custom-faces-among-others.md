# 元の VRM にあるカスタム表情も「その他」の位置に書く

- 日付: 2026-11-09
- 対象: `Editor/VrmMenuExpressions.cs`

## 背景

2026-11-08 の決定（`2026-11-08-expression-order.md`）で、書き出すカスタム表情をハンドジェスチャー → FaceEmo → その他（ボーンなし）→ その他（ボーンあり）の順にした。`Add` は書き出す表情を `custom` の後ろへ足すので、書き出しの前から `custom` に入っている表情（アバターの VRM に元からあるカスタム表情など）はハンドジェスチャーより前に来ていた。

## 決定

- 元からある表情は由来が分からないので「その他」に数える。その他のボーンなしの表情より前に、元の順のまま置く。
- 名前の重複の判定は並べ替えの前に終えているので、`custom` を一度空にして書き直しても、付く名前は変わらない。
- `expressions` の `source` の一覧には今までどおり入れない。書き出しが作っていない表情なので、由来を書けない。

## 検討した代替案と不採用理由

- その他のボーンなしの表情より後ろに置く: 元の VRM の表情は表情ボードで追加した表情より前に並ぶのが今の見え方で、群の中の順は変えない。
- 由来を `menu` として一覧に足す: 一覧に足すとアプリの「その他」の表情として扱いが変わる。今の表示は変えない。

## 確かめたこと

`ExpressionAnimationV2WriterTests.CustomFacesAlreadyInTheFileCountAmongTheOthers`: ハンドジェスチャー → FaceEmo → 元からある表情 → その他 の順になること、一覧には書き出した表情だけが載ること、その他が無くても元からある表情が残ること。
