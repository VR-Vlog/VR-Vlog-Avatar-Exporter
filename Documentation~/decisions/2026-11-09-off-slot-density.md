# 機能がオフのスロットは自動の軽量化の密度に数えない

- 日付: 2026-11-09
- 対象: `Editor/TexelDensity.cs`

## 背景

自動の軽量化は、同じテクスチャの使用箇所ごとに密度を求めて、大きいほうの値で縮める量を決める。密度が高いほど大きく縮む。

機能がオフのスロット（`_UseEmission` が 0 のときの `_EmissionMap` など）は、軽量化がオンなら `LilToonFullSnapshot` が空にして書き出す。ところが密度の計算には入っていたので、同じテクスチャを使う別のスロットが、描かれないスロットの密度で縮められていた。

## 決定

`TexelDensity.Measure` で `LilToonInactiveSlots.Sampled` が false のスロットを数えない。判定は書き出しで空にするときと同じものを使うので、「描かれないスロット」の定義が 2 か所に分かれない。

`NeverShrinks` の判定はこの前に置いたままにする。オフのスロットでも `_MatCapTex` などは共有先の縮小を止め続け、この PR の前と同じになる。

## 影響

変わるのは、オフのスロットの密度がオンのスロットより高い場合で、縮む量が減る。オフのスロットだけで使うテクスチャは測定されなくなり、等倍のまま書き出しで空になる。

例外が 1 つある。オフのスロットの tiling が 0 のように「測れない」値だった場合、これまでは等倍になっていたが、これからは測らないのでオンのスロットの密度で縮む。オフのスロットは空で書き出すので見た目は変わらない。

## 検討した代替案と不採用理由

- `NeverShrinks` より前で除外する: オフの `_MatCapTex` と共有するテクスチャが縮むようになり、今より縮む向きの変更になる。
- テクスチャごとに書き出す中身を見てから測る: 今の処理の順序を入れ替えることになり、修正の範囲に対して大きい。

## 確かめたこと

`TexelDensityTests.AFeatureOffSlotDoesNotRaiseTheDensity` と `ATextureOnlyInAFeatureOffSlotIsNotMeasured` を Unity 2022.3 で確かめた。結果は PR の本文に書く。
