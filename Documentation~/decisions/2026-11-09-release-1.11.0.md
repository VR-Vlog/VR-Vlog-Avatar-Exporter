# 書き出しの軽量化を、マイナーの安定版1.11.0として公開する

- 日付: 2026-11-09
- 対象: `package.json`・`Editor/ExportEntry.cs`（`PackageVersion` のフォールバック）・`CHANGELOG.md`・`README.md`・`README.en.md`・`Documentation~`・`Compatibility/AvatarPreservation.md`

## 背景

1.10.1のあと、developに#733から#744が入った。#744（フォールバック画像・16ビットインデックス・HDRキューブの軽量化）と#735（元のVRMにある表情の置き場所）で書き出す内容が変わる。

## 決定

- 機能の追加があるのでMINORを上げて `1.11.0` にする。
- `release/1.11.0` はdevelopの `2eb329c7`（#744のマージ）から作る。1.10.1のmainは#732でdevelopへ戻してあるので、mainの取り込みは要らない。
- `CHANGELOG.md` に `## 1.11.0` の節を足す。VR Vlog以外のVRMアプリでMToonの画像の解像度が下がることを、この節に書く。
- リリースには画像を添付しない。
- 版を書き換えるファイルと公開の手順は1.10.1と同じにする（[1.10.1の決定記録](2026-11-08-release-1.10.1.md)）。
