# 「自動で軽量化する」の既定オンを、マイナーの安定版1.12.0として公開する

- 日付: 2026-11-09
- 対象: `package.json`・`Editor/ExportEntry.cs`（`PackageVersion` のフォールバック）・`CHANGELOG.md`・`README.md`・`README.en.md`・`Documentation~`・`Compatibility/AvatarPreservation.md`

## 背景

1.11.0のあと、developに入った機能は#748（「自動で軽量化する」の既定をオンにする）だけ。設定を保存していないアバターの書き出しの結果が変わる。

## 決定

- 既定の動作が変わる機能の変更なのでMINORを上げて `1.12.0` にする。保存済みの設定と書き出しの形式は変えないのでMAJORにはしない。
- `release/1.12.0` はdevelopの `7610bbac`（#748のマージ）から作る。1.11.0のmainは#746でdevelopへ戻してある。
- `CHANGELOG.md` に `## 1.12.0` の節を足す。これまでにオフで保存されたアバターはオフのままであること、VR Vlog以外のVRMアプリでMToonの画像の解像度が下がることを、この節に書く。
- リリースには画像を添付しない。
- 版を書き換えるファイルと公開の手順は1.11.0と同じにする（[1.11.0の決定記録](2026-11-09-release-1.11.0.md)）。
