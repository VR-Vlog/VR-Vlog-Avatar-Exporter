# 書き出し結果の比較で、ビルドのたびに変わる名前のGUIDを伏せる範囲を広げる

- 日付: 2026-11-12
- 対象: `Tools/compare-exports.py`（`VOLATILE_SUB`、`VOLATILE_WARNING_SUB`、コンソールへの出力）、`Tools/test-compare-exports.py`、`CONTRIBUTING.md`

## 背景

ビルドの段でほかの骨組みに統合された骨は、名前の末尾に`$`とGUIDが付き、このGUIDがビルドのたびに変わる。`2026-11-12-compare-allow-added-extension.md`で、ノード名の末尾の`$<GUID>`を伏せてから比べるようにした。そのときに確かめたアバターは9体だった。

確かめるアバターを92体に増やし、拡張`VRVLOG_avatar_animator`を足す変更（#773）の前後を比べたところ、13組が「差あり」になった。差のあった値を取り出して数えると、足した拡張を除く差は、すべて同じGUIDが別の場所に出たものだった。

| 場所 | 形 | 件数 |
|---|---|---|
| ノード名 | `<名前>$<GUID>` | 278 |
| ノード名 | `<名前>$ConstraintRef <GUID>` | 14 |
| ノード名 | `<名前>$<GUID>-VRVlog Spring Endpoint` | 7 |
| `VRMC_springBone`の`springs`の名前 | `<名前>$<GUID>` | 150 |
| 警告 | `<名前>$<GUID>: <本文>` | 393 |

1行目は今までも伏せていた。2行目は、ビルドの段がConstraintのために足すオブジェクトの名前である。3行目は、統合された骨の下にExporterが足す揺れ物の末端で、親の名前を引き継ぐ（`2026-10-18-unique-spring-endpoint-names.md`）。4行目は、揺れ物の名前が先頭の骨の名前から付くためである。5行目は、警告が骨の名前で始まるためである。

もう1つ、Windowsのコンソール（コードページ932）でこの比較を流すと、警告に「—」などコードページに無い文字があるときに、差の行を出す途中で`UnicodeEncodeError`で止まった。差があるときに限って結果が読めなくなる。

## 決定

- `VOLATILE_SUB`のノード名の正規表現を、表の2行目と3行目の形まで広げる。`$`と`ConstraintRef `の間、GUIDの後ろの`-VRVlog Spring Endpoint`（名前が重なったときの` 2`・` 3`も）は伏せずに残し、GUIDだけを伏せる。それ以外の文字がGUIDの後ろに続く名前は、今までどおり差になる
- `VOLATILE_SUB`に`/extensions/VRMC_springBone/springs/*/name`を足す。末尾の`$<GUID>`だけを伏せる。コライダーなど`VRMC_springBone`のほかの名前は伏せない
- 警告用に`VOLATILE_WARNING_SUB`を足し、`$<GUID>`の直後が`: `のときだけGUIDを伏せる。骨の名前、本文、警告の数と順序は今までどおり比べる。差があったときに出す警告は、伏せる前の文字列にする
- コンソールが表せない文字は、止まらずに`\uXXXX`の形で出す。`--json`は、表せない文字があるときだけ全体をASCIIのJSONにして、JSONとして読める出力を保つ。UTF-8のコンソールでの出力は変わらない

## 検討した代替案と不採用理由

- 名前のどこにあってもGUIDの形を伏せる: 見ていない形まで通すと、名前の付け方が変わる変更を見落とす。実際に出た形だけを足す
- 警告を集合として比べる、または警告を比べない: 警告の順序や本文が変わる変更を見落とす。GUIDだけを伏せて、順序つきの比較を保つ
- 出力を常にUTF-8にする: コードページ932のコンソールで日本語の名前が読めなくなる。表せない文字だけを置き換える
- Exporterが名前からGUIDを取り除いて書く: 今の出力が変わる。前の決定と同じ理由で、比較の側で扱う

## 確かめたこと

- `Tools/test-compare-exports.py`の52件が通る。足した7件は、表の4つの形でGUIDだけが違う入力が一致になること、名前・接尾辞・本文・順序が違う入力やGUIDの後ろに別の文字が続く入力が差のままであること、ASCIIのコンソールで「—」を含む差が終了コード1で最後まで出ること、`--json`の出力がJSONとして読めることを見る
- 92体（書き出せた89体と、変更の前後とも同じ理由で書き出せない3体）を、拡張を足す変更の前後で比べた。直す前は`92 pairs, 13 mismatched`、直した後は`92 pairs, 0 mismatched`になった。直す前の13組について、足した拡張を除く差のある値を取り出し、GUID以外が違う値が0件であることを別のスクリプトで数えた
- 前の決定で確かめた9体の2回ずつの書き出しを、直したツールで比べ直した。`--runs <dir> 1 2`は変更の前後のどちらも`9 pairs, 0 mismatched`のままだった
