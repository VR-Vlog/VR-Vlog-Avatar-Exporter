# 書き出し設定を保存できなかった理由を表情ボードに出す

- 日付: 2026-11-12
- 対象: `Editor/ExportSettingsStore.cs`（`Problem`）、`Editor/ExperimentalExpressionCaptureWindow.cs`（`DrawFeedback`）

## 背景

書き出し設定（`UserSettings/VRVlogLilToonExporter/ExportSettings.json`）を保存できないとき（書き込めない・読めない・別の版のファイルがある）、`ExportSettingsStore` は何も保存せず、理由をコンソールに警告するだけだった。警告は同じ理由で 1 回しか出ないので、表情ボードで視線の範囲やまばたきを変えても保存されていないことが、ボードの画面からは分からなかった。

視線の欄の保存（#764）は書き込みの例外を投げずにコンソールに残すが、ファイルの問題はその前に `ExportSettingsStore` が受け止めていて、例外にはならない。画面に出ない原因は視線の欄ではなく保存の側にある。

## 決定

- `ExportSettingsStore.Problem` に、最後に何も保存できなかった保存の理由を持つ。書き込めた保存で消える。コンソールの警告は今までどおり理由ごとに 1 回。
- 表情ボードは、エラーが無いときにこの理由を警告として結果の欄（`DrawFeedback`）に出す。視線のスライダーは離したときに同じフレームの途中で保存するので、表示する値は Layout のときに読み、変わったら描き直す。

## 検討した代替案と不採用理由

- 視線の欄の保存（`GazeRangeSection.Unsaved.Save`）が例外の文を返し、ボードの `error` に出す: ファイルの問題は例外にならないので、実際に起きる失敗が出ない。`error` は次の操作が成功すると消えるので、アバターを変えたときの保存の失敗はすぐ消える。
- 表情の割り当ての保存（`ExpressionPresetStore`）も同じ値に入れる: 別のファイルで、書き込みの失敗は例外としてボードのエラーに出ている。読めないファイルのときだけ警告になる点は別の作業にする。
