# 段を外した理由の文を上限超えでも合うようにし、画面に出る大きさの単位を MB にそろえる

- 日付: 2026-11-14
- 対象: `Editor/ExportResultList.cs`・大きさの上限を出す 8 か所の文・`Editor/Locales/ExporterLocale_*.json`・`Tests/Editor/VrChatMenuExpressionTests.cs`

## 背景

- 書き出しの結果一覧では、外した段（`ExportStageGuard` の段）の行の内容に「処理に失敗したため省きました」「処理に失敗したため簡易な形にしました」と出し、その下の「理由」に段が投げた文を出す。段は上限を超えたときにも外れる（表情の追加データが 128MB を超える、lilToon の JSON が 8MB を超えるなど）。このとき内容は「失敗した」、理由は「上限を超えています」となり、食い違って読める（Codex の指摘）。
- 画面に出る大きさの上限は、「128 MiB」「256MiB」「8MiB」「16MB」と書き方がばらばらだった。ポーズの上限（16MB）と転送の大きさの表示（`TransferSizeText`）は MB と書き、1MB を 1024×1024 バイトとして数えている。
- 韓国語・中国語の「循環」の文には、参照が「순환하고 있습니다」（循環して動いている）と読める訳と、「Animator 상태 기계 순환 또는 수 한계.」のように文になっていない訳があった。英語は同じ文を「contains a circular reference」の形で直したことがある。

## 決定

- 段の行の内容を「処理を終えられなかったため省きました」「処理を終えられなかったため簡易な形にしました」にする。例外で止まったときも上限で止まったときも当てはまり、何が起きたかは「理由」が言う。英語・韓国語・中国語も同じ意味に直した。
- 画面に出る大きさの上限は、数字と `MB` を空けずに書く（例: `128MB`・`256MB`・`8MB`）。上限の値は変えない。中国語は、表のほかの訳と同じく英数字の前後を空ける（例: `超过 128MB 上限`）。
- 韓国語の「循環」の文は、参照の循環を「순환 참조가 있습니다」（循環参照があります）の形にし、壊れていた 1 件を文にした。中国語は参照の循環を「存在循环引用」「存在循環參照」にした。どちらも、ほかの「循環」の文（遷移の循環・サブメニュー・コンストレイント）は意味が合っているので変えていない。

## 変えないもの

- 決定記録・技術資料（`Documentation~/LanTransfer.md`・`HumanoidAnimations.md` など）の `MiB` は、バイト数を正確に言う場面なのでそのままにした。変更履歴の過去の項目も変えていない。
- 訳の表に残っている、コードから使われなくなった 2 件（「256 MiB以下の保存済みVRMを指定してください。」と「追加表情の形状データが128 MiBを超えます。」）は画面に出ないので触っていない。

## 残ること

- 韓国語・中国語の直しはこの変更を書いたエージェントが行ったもので、母語話者は読んでいない。
