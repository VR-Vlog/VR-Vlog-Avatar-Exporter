# かんたんの軽量化の行を、1.17.0として公開する

- 日付: 2026-11-26
- 対象: `package.json`・`Editor/ExportEntry.cs`（`PackageVersion` のフォールバック）・`CHANGELOG.md`・`README.md`・`README.en.md`・`Documentation~`・`Compatibility/AvatarPreservation.md`

## 背景

1.16.1のあと、developに#865と#866が入った。#866はアプリに転送（かんたん）の名前の下に、表情ボードと同じ軽量化のなし・標準・最大を足す（[決定記録](2026-11-26-quick-transfer-lightweight.md)）。#865はPRのCIでZIPのリンクを確かめる検査で、パッケージの中身は変わらない。mkから、#866を入れたらリリースするよう指示があった。

## 決定

- MINORを上げて `1.17.0` にする。かんたんのウィンドウに項目が増える（#866）。
- `release/1.17.0` はdevelopの `d8ffd3cb`（#866のマージ）から作る。
- `CHANGELOG.md` に `## 1.17.0` を足し、Releaseの本文に使うので1行の説明だけにする。#865はCIだけなので項目にしない。
- 公開の前に、1.16.1と1.17.0でEditModeテストを回して新しい失敗が無いことを確かめる（結果はPRに書く）。
- リリースには画像を添付しない。見た目は#866のPRにある。
- バージョンを書き換えるファイルと公開の手順は1.16.1と同じにする（[1.16.1の決定記録](2026-11-26-release-1.16.1.md)）。
