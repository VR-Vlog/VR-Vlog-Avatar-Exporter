# Modular Avatarの上限の撤廃を、2.0.1として公開する

- 日付: 2026-11-27
- 対象: `package.json`・`Editor/ExportEntry.cs`（`PackageVersion` のフォールバック）・`CHANGELOG.md`・`README.md`・`README.en.md`・`Documentation~`・`Compatibility/AvatarPreservation.md`

## 背景

2.0.0のあと、Modular Avatar 1.19.0と1.19.1が正式に出て、1.19以降を入れたプロジェクトではShape Changerなどを使うアバターが書き出しの前に止まるようになった。mkから、上限を外してパッチリリースを急いで出すよう指示があった（2026-11-27）。developには、上限の撤廃（#882、[決定記録](2026-11-27-ma-no-upper-bound.md)）と、書き出し中のバーに処理の名前とキャンセルのボタンを出す修正（#881）が入っている。

## 決定

- PATCHを上げて `2.0.1` にする。どちらも不具合の修正で、書き出すVRMの形は2.0.0と同じ。パッケージの依存（`vpmDependencies`）とUnityの対応バージョンも2.0.0と同じ。
- `release/2.0.1` はdevelopの `bf57d300`（#882のマージ）から作る。
- `CHANGELOG.md` の「未リリース」を `## 2.0.1` にし、#881の1行を足す。Releaseの本文に使うので、見出しを除いて5行に収める。
- リリースには画像を添付しない。
- 急ぎのため、v2.0.0との全件のEditModeテストの比べ直しはしない。#882はMA 1.18.7と1.19.1の両方で固定のテスト24件を回して同じ結果になることを、#881はそのPRで書き出しのテストを確かめている。PRのCIと、mainに入ったときのBuild release candidateの検査（`Tools/run-validation.py` とZIPの検査）は通す。
- バージョンを書き換えるファイルと公開の手順は2.0.0と同じにする（[2.0.0の決定記録](2026-11-27-release-2.0.0.md)）。
