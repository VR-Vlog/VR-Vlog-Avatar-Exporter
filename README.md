# VR Vlog lilToon VRM Exporter

[日本語](README.md) · [English](README.en.md)

lilToonのアバターを、VR Vlogで使えるVRM 1.0形式に書き出すUnity用ツールです。

MITライセンスで公開しています。

[![MIT License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

## 対応環境

| 必要なもの | バージョン・導入方法 |
| --- | --- |
| Unity | 2022.3 |
| lilToon | バージョンを問わず書き出せます。アプリではlilToon 2.3.4として描画するので2.3.4を推奨します（1.0.0以降と0.12.0-beta.4以降。それより前は、0.12.0-beta.1〜beta.3が2.0.0〜2.3.4、安定版0.11.15が2.3.4だけ）。VCC・ALCOMのほか、unitypackageで`Assets`の下に入れたlilToonでも書き出せます |
| UniVRM | 導入不要。UniVRM 0.131.4を名前空間・シェーダー名を変えて同梱しているので、導入済みのUniVRMとはバージョンにかかわらず衝突しません |
| VR Vlog | 0.1.1（ビルド345）以降 |
| VRChat SDK | 任意。3.5.0以上3.11.0未満（3.11.0未満のベータ版を含む）で確認しています。音声再生（VRC Animator Play Audio）を含む表情ファイルを使う場合は、3.5.2以上3.11.0未満が必要です |
| NDMF | 任意。Modular AvatarなどNDMFで動くツールを使うアバターは、NDMF 1.6.0以上2.0.0未満の正式版が必要です。Modular Avatar 1.19.0-alpha.2用に、プレリリースの1.15.0-beta.1・beta.2も通します |
| Modular Avatar | 任意。Shape Changer・Object Toggle・Material Setter・Material Swap・Mesh Cutterを使うアバターは1.12.2以上1.19.0未満か、プレリリースの1.19.0-alpha.2。これらを使わないアバターはバージョンを問いません |

Modular Avatarを使う場合は、事前に導入してください。

**注意**

- lilToonのバージョンでは書き出しを止めません。1.x・2.3.4より新しいバージョン・プレリリースでも書き出し、アプリでは導入済みのバージョンにかかわらずlilToon 2.3.4として描画します。
- 2.3.4とシェーダーが違うところは、書き出し画面に警告として一覧で出して書き出しを続けます。2.3.4にないプロパティは書き出さず、2.3.4のプロパティと合わないマテリアルはMToonで近似します。Unityとアプリで同じ見た目にするには2.3.4を使ってください。
- 止まるのは、lilToonが入っていないときと、ベイク用シェーダー（`Hidden/ltsother_baker`）が2.3.4と違うときだけです。[互換性の詳細](Compatibility/README.md#supported-liltoon-versions)

## インストール

**[インストールページを開く](https://vrvlog.fun/exporter/)** · [変更履歴](CHANGELOG.md)

1. 「VCC / ALCOMに追加」を押す。
2. VCC・ALCOMで、使いたいプロジェクトのパッケージ管理画面を開く。
3. 「VR Vlog lilToon VRM Exporter」を追加する。

<details>
<summary>追加ボタンで開かない場合</summary>

VCC・ALCOMのリポジトリ追加画面に、次のURLを貼り付けてください。

```text
https://vrvlog.fun/exporter/index.json
```

以前の個人側・組織側のURLを登録済みなら、そのまま使えます。

</details>

<details>
<summary>インストーラーのunitypackageで導入する場合</summary>

VCC・ALCOMを開かずに、Unityで開いているプロジェクトへ入れられます。

1. [Releases](https://github.com/VR-Vlog/VR-Vlog-Avatar-Exporter/releases)から `com.vrvlog.liltoon-vrm-exporter-installer-<版>.unitypackage` をダウンロードする。
2. Unityで開いているプロジェクトのProjectウィンドウへドラッグ&ドロップし、Importを押す。
3. 確認の画面で「Install」を押す。このリポジトリ（`https://vrvlog.fun/exporter/index.json`）がプロジェクトとVCC・ALCOMに登録され、エクスポーターが `Packages` に入る。インストーラーのファイルは終わると自動で消える。

インストーラーは、ダウンロードした版と同じ系列（1.0.0のインストーラーなら2.0.0より前の1.x、0.12.0のインストーラーなら0.12.x）のうち、VPMの一覧にある最新の版を入れます。ベータ版のインストーラーはベータ版も選びます。Releaseに出た直後で一覧にまだ載っていない版は入らないので、少し待ってからやり直してください。特定の版を入れたいときはZIPで導入してください。

</details>

<details>
<summary>ZIPで手動導入する場合</summary>

1. [インストールページ](https://vrvlog.fun/exporter/)の「ZIPで導入」を開く。
2. エクスポーターのZIPをダウンロードする。
3. `Packages` 内のフォルダーへ展開する。
4. フォルダーの直下に `package.json` があることを確認する。
5. Unityの読み込みが終わるのを待つ。

</details>

## 使い方

安定版1.3.5の手順です。

### 1. アバターを準備

Unityで、書き出すアバターと衣装を表示します。親オブジェクトも有効にしてください。

### 2. 表情ボードを開く

Hierarchyでアバターの一番上のオブジェクトを選び、メニューの **VR Vlog → アプリに転送（通常）...** を選びます。Hierarchyでアバターを右クリックしたときの **VR Vlog** にも同じ項目があります（[右クリックでアプリに転送する](#右クリックでアプリに転送する)）。prefabとして保存したアバターは、Projectでそのprefabを右クリックしたときの **VR Vlog** からも同じように開けます。VRMファイルだけを保存するときも、この表情ボードの3ページ目の **VRMを保存** を使います。

### 3. アバターを確認

表情ボードが開き、選んだアバターで「書き出しを準備」まで進みます。別のアバターにするときは、1ページ目の「アバター」欄の横の「変更」を押します。

### 4. 表情を割り当てる（任意）

見つかった表情は、すべて「その他の表情」（VRMのカスタム表情）に入ります。

- **割り当て：** 表情をVRMの表情5枠（喜び・怒り・悲しみ・安らぎ・驚き）へドラッグ＆ドロップします。右クリックのメニューでも移せます。
- **除外：** 使わない表情は「書き出さない表情」へ移します。
- **確認：** 表情を押すとプレビューできます。
- **追加：** `.anim` を「その他の表情」へドロップします。

表情の名前（その表情を出すVRChatメニューの項目名も含みます）から自動で入った枠は「自動の候補○件を確定」で確定できます。表情を割り当てずに保存することもできます。

選んでから2秒で顔が止まらないメニューの表情（少し待ってから切り替わる・長いアニメーション・ループ）は、Animatorの遷移をたどった最終状態の顔で書き出し、書き出し結果の一覧に「近似」として表示します。

### 5. 保存

表情ボードは「1 表情の設定 › 2 除外するオブジェクト › 3 VRMの保存と転送」の3ページに分かれています。1ページ目で表情・瞬き・任意の全身ポーズを決め、下の **次へ：除外するオブジェクト** を押します。2ページ目でVRChat用のギミックと手で外すオブジェクトを確認し（右側の全身のプレビューに、外したものがその場で消えます）、**次へ：VRMの保存と転送** を押すと、変えた除外をプレビューに反映してから3ページ目へ移ります。3ページ目には名前・**作者名**・**VRMの利用条件** の欄があり、下に **VRMを保存** と **QRコードを作る** が並びます。**作者名** を入力し、**VRMの利用条件** を確認して **VRMを保存** を押します。保存だけなら利用規約への同意は要りません。

全身ポーズがアプリの上限（128件、動くポーズのフレーム合計32,768、動くポーズのデータ16MB、静止ポーズのデータ2MB）を超えるときは、書き出しの途中で **アプリの上限を超えた項目** の画面が1回だけ開きます。既定ではリストの末尾から外すので、残すポーズを選び直して **この内容で書き出す** を押します。選んだ内容はアバターの書き出し設定に保存し、次の書き出しと **アプリに転送（かんたん）** でも使います。外したポーズは書き出し結果の一覧に「同梱ポーズ」として表示します。上限内なら画面は開きません。

保存後は「保存先を開く」でファイルを確認できます。

アプリで髪や体が消える・透けるときは、書き出し結果のウィンドウか **アプリに転送** の完了画面の **診断情報をコピー** を押し、コピーした文字列を不具合の報告に貼ってください。メッシュとマテリアルの数値、書き出さなかったギミックの種類と数（外したギミック・カメラや音などのVRMに入らない部品・PhysBoneとコンストレイントの変換前後の数）と変換の内容だけで、アバター名・オブジェクト名・作者名・パスは入りません。

開発者からDMなどで詳しい情報を頼まれたときは、**診断情報をコピー** の右の **▾** から **名前・パスを含めてコピー（DM など非公開の場だけ）** を選んでください。同じ内容に、アバター名、メッシュとマテリアルの名前・元のシェーダー名、外したギミックと部品の場所、変換の内容の文面と対象のパスを足した別の文字列をコピーします。先頭に「名前・パスを含みます。DM など非公開の場だけで送ってください」と入ります。公開のチャンネルやIssueには貼らないでください。

### ライセンス設定

利用条件を設定する場合は、3ページ目の **VRMの利用条件** を開き、元の利用規約に合わせてプルダウンを選びます。規約URL（VN3等）、著作権表示、第三者ライセンスも入力できます。設定は出力VRMのメタデータに保存されます。設定を開かない場合は、このアバターで前に書き出したときの設定で書き出します。記録が無ければ既定値（作者のみ・個人非営利・クレジット表記が必要・表現用途の各許可なし・再配布と改変なし）です。

### アプリでの見え方を確認

保存したVRMを、VR Vlogアプリと同じ読み込み処理で開いて確認する画面です。1.0.0以降には、この画面を開くボタンとメニューがありません。開いた画面では、ほかの `.vrm` を **VRM ファイルを開く** で選べます。

- 材質: アプリと同じ表示（lilToon専用表示）か、標準のMToonだけの表示かを切り替えます。lilToonで表示できたか、MToonで表示した材質の件数と理由を表示します。lilToonは公式のBuilt-in版シェーダーで描くため、アプリのURP版とは細部が異なることがあります。
- 表情: VRMの表情を1つずつ適用し、表情アニメーションを再生します。
- まばたき: 自動のまばたき（4秒ごと）か、目の閉じ具合のスライダーで確認します。自動のまばたきはこの画面だけの確認用の動きで、アプリのまばたきの間隔とは関係ありません。
- 揺れもの: アバターを左右に揺らして揺れものの動きを確認します。

この画面は、VR Vlogアプリの読み込みパッケージ（`com.vrvlog.avatar-runtime`）がプロジェクトに入っているときだけ使えます。このパッケージは一般には配布していません。入っていなくても書き出しは今までどおり動きます。

パッケージを参照するのは `Editor/AppPreview/AvatarRuntimeBackend.cs`（`VRVlog.LilToonExporter.AppPreview` アセンブリ）だけです。画面はこのファイルが登録するインターフェイス（`Editor/AppPreviewEntry.cs` の `IAppPreviewBackend`）だけを使います。パッケージの置き場所や名前が変わったときは、このファイルとアセンブリ定義だけを直します。

## 書き出したVRMをスマホで読み込む

### QRコードで転送する

QR対応の最新iPhone TestFlight版が必要です。Android配布版では受信できません。

PCとスマホをインターネットに接続してください。

1. Hierarchyでアバターを右クリックし、**VR Vlog → アプリに転送（かんたん）...** か **アプリに転送（通常）...** を選ぶ（[右クリックでアプリに転送する](#右クリックでアプリに転送する)）。
2. 名前・作者名を確認し、利用規約に同意する。初回はプライバシーポリシーも確認して同意する。
3. **QRコードを作る** を押し、アップロードが終わったら **QRを表示** を押す。
4. スマホのカメラでQRを読み取り、VR Vlogで受け取る。受け取りが終わると、PCに **アプリに取り込みました** と出る。

**注意**

**QRを持つ人はアバターを受け取れます。他人へ見せないでください。**

転送時は、暗号化したVRMをクラウドへ一時保存します。[転送の詳細・同意事項](Documentation~/CloudTransfer.md)

### 右クリックでアプリに転送する

Hierarchyでアバターの一番上のオブジェクトを右クリックし、**VR Vlog** から2つのどちらかを選びます。上のメニューバーの **VR Vlog** にも同じ項目があり、Hierarchyで選んでいるアバターを転送します。アバターの一番上のオブジェクトを1つだけ選んでいないときは、どちらの項目も灰色で選べません。QRはスマホのカメラで読み取ります。

Projectでアバターのprefabを右クリックしたときの **VR Vlog** にも同じ項目があり、そのprefabを転送します。シーンに置かなくても転送・保存でき、開いているシーンとprefabは変わりません。prefabを1つだけ選んでいないときや、選んだprefabの一番上にAnimatorが無いときは灰色で選べません。

右クリック（HierarchyとProject）とメニューバーの **VR Vlog** には、どれも **アプリに転送（かんたん）...** と **アプリに転送（通常）...** の2つが並びます。Projectの右クリックでは、そのあとに区切り線と **Validate lilToon VRM** が続きます。VRMファイルだけを保存するときは、**アプリに転送（通常）** の3ページ目で **VRMを保存** を押します。

| メニュー | 向いているとき | 流れ |
| --- | --- | --- |
| **アプリに転送（かんたん）** | 表情やオブジェクトを選ばずにすぐ送る | 名前・作者名・利用規約の同意を確認 → **QRコードを作る** |
| **アプリに転送（通常）** | 使う表情を選ぶ・不要なオブジェクトを外す | 表情ボードで割り当てる → **次へ：除外するオブジェクト** で外すものを選ぶ → **次へ：VRMの保存と転送** → **QRコードを作る** |

入力が必要なのは、名前・作者名・利用規約への同意（毎回）・プライバシーポリシーへの同意（初回だけ）です。ライセンスは **VRMの利用条件** を開いて変えられます。開かない場合は前回の設定か既定値で書き出します。

- **かんたん：** 名前と作者名は、このアバターで前に転送したときの値が入ります。書き出す内容は、表情ボードで何も変えずに **アプリに転送（通常）** で書き出した場合と同じです（表情はこのアバターで前に表情ボードで決めた割り当て、無ければ自動で選んだもの。空の neutral と視線は名前から埋め、視線は両目が動く名前がそろったときだけ使います。書き出さないオブジェクトは前回の設定）。違いは、書き出し結果の確認を出さずに転送することだけです。書き出しを止める問題があるときは、理由を表示して止まります。**表情とオブジェクトを選ぶ** で通常に切り替えられます。ウィンドウの幅が足りるときは、フォームの右の「プレビュー」に書き出すアバターの全身を表示します（書き出さないオブジェクトは表示しません。操作はUnityのSceneビューのマウス操作と同じで、ドラッグで回転、中ドラッグで移動、右ドラッグで見回し、ホイールで拡大、Fで全身を表示。WASDでの移動はありません。一覧はプレビューにマウスを重ねると出ます）。色と透け方はアプリと異なる場合があります。
- **通常：** 表情ボードの1ページ目で表情を割り当て、**次へ：除外するオブジェクト** を押して外すものを追加し、**次へ：VRMの保存と転送** を押します。変えた除外をプレビューへ反映してから、3ページ目「3 VRMの保存と転送」で転送の画面を表示します。表情の割り当ては [4. 表情を割り当てる](#4-表情を割り当てる任意) と同じです。ボタンの左の **戻る** で2ページ目に戻ります。アップロード中とQRの表示中に **戻る** を押すと「このQRコードは使えなくなります」と確認し、**中止して移動** で転送を中止して2ページ目に戻り、**転送を続ける** でそのまま残ります。表情ボードを閉じると、確認せずに進行中の転送を中止します。
- **VRMを保存：** どちらの画面にも **QRコードを作る** の左にあります。転送で送るのと同じVRMを、表情ボードの保存と同じ保存先の画面で `.vrm` に保存します。利用規約とプライバシーポリシーの同意は要りません（作者名は要ります）。アップロード中とQRの表示中も使え、転送はそのまま続きます。転送から開いたときは **QRコードを作る** が青いボタンです。

### ファイルを手動で読み込む

1. 書き出した `.vrm` をスマホに保存する。
2. VR Vlogの設定で「lilToon専用表示」をオンにする。
3. 「モデルを変更 → 端末のVRMを選ぶ」でファイルを選ぶ。

## 対応範囲

### 対応するもの

- lilToonの材質・画像
- 表情、ポーズ、瞬き、顔トラッキング用の変形
- FXの通常状態で一定に保たれる顔・体形（待機中のFXで口や目を開いたままにする設定など）。VRMの基準形に保存します。時間で変わる変形は書き出し用コピーの値を保持します
- Modular Avatarで設定した髪・衣装
- PhysBoneの揺れ物
- Expression Menuのトグルで切り替えるオブジェクトの表示（帽子・眼鏡・衣装の着替えなど）。既定で非表示のものも書き出し、アプリで項目ごとに表示を切り替えられます。読めるのは対応版のアプリだけで、それより前のアプリでは既定で非表示のものも表示されます

### 再現しないもの・違いが出るもの

- VRChatのギミック全般、一部のシェーダー効果
- メニューの表示切り替えのうち、2つ以上のパラメーターの組み合わせで決まる表示、同じトグルが変えるBlendShapeと材質、Toggle以外の項目（Button・Puppet）
- lilToon以外のシェーダーの材質。公式lilToonの材質に置き換え、主画像・色・透過・法線マップ・発光・影色だけを引き継ぎます。元のシェーダーの色調補正は、主画像の明るさを一律に変えるものだけを引き継ぎ、色相・彩度・ガンマ・グラデーション・マスク付きの補正は反映しません。置き換えた材質と、反映しなかった色調補正は保存前に表示します。
- 透過を独自の式で決めるトゥーンシェーダー（切り抜きマスクに値を足して切り抜くもの、アルファの元をマスクから選ぶもの、アルファの倍率と輝度のマスクを持つもの、両面をジオメトリシェーダーで描くもの、VRM 0.xのMToon）は、その式を公式lilToonのアルファマスクで組み直し、両面・深度の設定も引き継ぎます。混ぜる量と切り抜く境界を別々に持つ半透明は、混ぜる量に合わせます。
- 照明の種類（`_LightingMode`）や効果ごとの切り替えを持つトゥーンシェーダーの材質は、項目ごとに公式lilToonの同じ役割の項目へ写します。影（照明の種類ごとの境界とぼかし、影色、2つ目の影）、明るさの上限と下限、色調補正（色相・彩度・明るさ・ガンマ・グラデーション）、マットキャップ2つ、リムライト、輪郭線、発光（点滅を含む）、アルファマスク、ステンシルが対象です。公式lilToonに無い効果（デカール・ディゾルブ・グリッター・AudioLinkなど）は書き出さず、材質名と効果名を保存前に表示します。色相（元がOKLabの場合）・彩度・ランプ画像の影は近い値への置き換えで、元と完全には一致しません。
- VRChat SDKの公式シェーダー（Toon Standard・Mobile・Standard Lite・Sprites・UI・Video・Panosphere・Mirrorなど）の材質は、シェーダーごとに公式lilToonの同じ役割の項目へ写します。影、スペキュラー、マットキャップ、リムライト、ディテール、輪郭線、加算・乗算の合成を引き継ぎ、色相と色のマスクは主画像に焼き込みます。投影（Panosphere）・キューブマップ・鏡の反射は書き出さず、保存前に表示します。
- 揺れ方の完全な再現。VRM向けの近似になります。PhysBoneのImmobileは、All Motionのとき揺れの強さと減衰に反映し、Worldのときはアプリの安定化に任せます。
- VRChatと同じ顔・体形。設定によって見た目が異なる場合があります。

他のビューアーではMToon表示になり、見た目や動く表情が異なる場合があります。

### 書き出しで自動的に外すもの

**補助ギミックを自動除外** がオン（既定）のとき、VRMでは働かない次のものを書き出しから外します。外したものと、判断がつかず残したものは書き出し結果の一覧に表示します。

- VRChatの中でだけ動くギミック。Modular Avatarのメニューやアニメーターの組み込みを持ち、カメラ・音・パーティクル・ライト・接触・コンストレイントのどれかを含み、アバターと同じ系統の材質（lilToon・MToonや、体と同じシェーダー）を使っていない見た目を持つものを、そのまま丸ごと外します。体のボーンに付く衣装・小物と、アバターと同じ系統の材質で描かれたぬいぐるみなどの小物は残します。VRChatの中でだけ動く部分が見つからないものは外さずに一覧に表示します。
- Modular AvatarのPlatform Filterで、VRM向けの書き出し（汎用のプラットフォーム）から外す指定があるオブジェクト。含める指定と外す指定が混在しているものは外さずに一覧に表示します。
- アバターのポーズを付ける仕組み。ポーズはアプリで付けるため外します。名前ではなく働きで見分けます。
  - 胴や脚を動かすポーズのアニメーションを持つもの。手・指・頭・表情だけのアニメーションは対象外です。体のボーンに付く衣装・小物と、VRChatのAvatar Descriptorは残します。
  - 書き出しの前の処理で体のボーンを別の場所へ付け替えるもの（Modular AvatarのWorld Fixed ObjectとHipsに付けたBone Proxyを持つもの）。VRMでボーンの親子が崩れ、アプリでポーズが付かなくなります。
- 見た目もボーンも持たない空のオブジェクト（VRChatのメニューや設定だけを持っていたものなど）。VRMには入れません。外した数はConsoleに表示します。

外したくないギミックは、表情ボード（**アプリに転送（通常）**）の2ページ目 **除外するオブジェクト** にある **VRChat用のギミック** で **含める** を選ぶと残せます。VRMに入れても、VRChatの中での動きは再現されません。選んだ内容はアバターの書き出し設定に保存します。表情ボードでは、選んだ内容を2ページ目の右側の全身のプレビューにはその場で、VRMにはページを移るときに反映します。ボーンを付け替える仕組みを **含める** にすると、ヒューマノイドのボーンの親子が崩れるため書き出しを止め、崩れたボーンの名前を出します。

## 困ったとき

<details>
<summary>エラーで書き出しが止まる</summary>

書き出し画面の「書き出しの詳細」を開きます。エラーが起きた対象と、表示された対処方法を確認してください。

対策候補が表示された場合は、再試行できます。成功したら、見た目を確認してVRMを保存してください。

</details>

<details>
<summary>必要なパッケージが足りない・対応版ではない</summary>

書き出せないときは、**アプリに転送** の画面に **VR Vlog 動作環境** が出ます。押すと、不足しているパッケージや未対応のバージョンが表示されます。画面の案内に従って導入・更新し、もう一度書き出してください。

</details>

<details>
<summary>衣装が出力されない</summary>

Unityで、その衣装が表示されているか確認してください。非表示の衣装は出力されません。表示しても出ない場合は、アバターへの接続設定を確認してください。

</details>

<details>
<summary>瞬きで目がうまく閉じない</summary>

閉眼用の変形を自動で決められないときは、瞬きなしで保存し、警告に理由を表示します。瞬きを入れるときは次の手順で選んでください。

1. 表情ボードの1ページ目にある瞬きの「確認・調整」を開く。
2. 「手動」に切り替え、顔のメッシュと閉眼用の変形を選ぶ。
3. プレビューで目の開閉を確認し、「設定を適用」を押す。
4. VRMを保存する。

</details>

<details>
<summary>解決しない場合の問い合わせ</summary>

[不具合報告](https://github.com/VR-Vlog/VR-Vlog-Avatar-Exporter/issues/new/choose)に、次の内容を添えてください。

- Unityとエクスポーターのバージョン
- 問題が起きるまでに行った操作
- エラー画面でコピーした共有用の診断

VR Vlogアプリ内の問い合わせも利用できます。

</details>
