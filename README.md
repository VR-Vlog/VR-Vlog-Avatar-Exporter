# VR Vlog lilToon VRM Exporter

[日本語](README.md) · [English](README.en.md)

lilToonのアバターを、VR Vlogで使えるVRM 1.0形式に書き出すUnity用ツールです。

MITライセンスで公開しています。

[![MIT License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

## 対応環境

| 必要なもの | バージョン・導入方法 |
| --- | --- |
| Unity | 2022.3 |
| lilToon | 2.0.0〜2.3.4（0.12.0-beta.1以降。安定版0.11.15は2.3.4だけ） |
| UniVRM | 0.131.x（0.131.0〜0.131.3で確認済み）。VCC・ALCOMでは自動導入 |
| VR Vlog | 0.1.1（ビルド345）以降 |
| VRChat SDK | 任意。音声再生（VRC Animator Play Audio）を含む表情ファイルを使う場合は3.5.2以上3.11.0未満 |
| Modular Avatar | 任意。Shape Changer・Object Toggle・Material Setter・Material Swap・Mesh Cutterを使うアバターは1.18.0以上1.19.0未満。これらを使わないアバターは版を問いません |

Modular Avatarを使う場合は、事前に導入してください。

**注意**

- lilToonの対応範囲外・プレリリース版では書き出せません。
- 対応版でも、シェーダーの構成が異なる場合は停止します。[互換性の詳細](Compatibility/README.md#supported-liltoon-versions)

## インストール

**[インストールページを開く](https://vrvlog.fun/exporter/)** · [変更履歴](CHANGELOG.md)

1. 「VCC / ALCOMに追加」を押す。
2. VCC・ALCOMで、使いたいプロジェクトのパッケージ管理画面を開く。
3. 「VR Vlog lilToon VRM Exporter」を追加する。

<details>
<summary>追加ボタンで開かない場合</summary>

VCC・ALCOMのリポジトリ追加画面に、次のURLを貼り付けてください。

```text
https://vrvlog.fun/exporter/index.json
```

以前の個人側・組織側のURLを登録済みなら、そのまま使えます。

</details>

<details>
<summary>ZIPで手動導入する場合</summary>

1. [インストールページ](https://vrvlog.fun/exporter/)の「ZIPで導入」を開く。
2. エクスポーター・UniGLTF・VRMの3つのZIPをダウンロードする。
3. `Packages` 内の別々のフォルダーへ展開する。
4. 各フォルダーの直下に `package.json` があることを確認する。
5. Unityの読み込みが終わるのを待つ。

同じUniVRMパッケージを重複して導入しないでください。

</details>

## 使い方

安定版0.11.15の手順です。

### 1. アバターを準備

Unityで、書き出すアバターと衣装を表示します。親オブジェクトも有効にしてください。

### 2. 書き出し画面を開く

メニューの「VR Vlog → VRMを書き出す」を選びます。

### 3. アバターを指定

Hierarchyのアバター最上位を「アバター」欄に指定します。「書き出しを準備」を押します。

### 4. 表情を割り当てる（任意）

見つかった表情は、すべて「その他の表情」（VRMのカスタム表情）に入ります。

- **割り当て：** 表情をVRMの表情5枠（喜び・怒り・悲しみ・安らぎ・驚き）へドラッグ＆ドロップします。右クリックのメニューでも移せます。
- **除外：** 使わない表情は「書き出さない表情」へ移します。
- **確認：** 表情を押すとプレビューできます。
- **追加：** `.anim` を「その他の表情」へドロップします。

表情の名前（その表情を出すVRChatメニューの項目名も含みます）から自動で入った枠は「自動の候補○件を確定」で確定できます。表情を割り当てずに保存することもできます。

選んでから2秒で顔が止まらないメニューの表情（少し待ってから切り替わる・長いアニメーション・ループ）は、Animatorの遷移をたどった最終状態の顔で書き出し、書き出し結果の一覧に「近似」として表示します。

### 5. 保存

表情ボードは「1 表情の設定 › 2 除外するオブジェクト › 3 VRMの情報」の3ページに分かれています。1ページ目で表情・瞬き・任意の全身ポーズを決め、下の **次へ：除外するオブジェクト** を押します。2ページ目でVRChat用のギミックと手で外すオブジェクトを確認し、**次へ：VRMの情報** を押すと、変えた除外をプレビューに反映してから3ページ目へ移ります。3ページ目で **作者名** を入力し、**ライセンス設定** を確認して **VRMを保存** を押します。

全身ポーズがアプリの上限（128件、動くポーズのフレーム合計32,768、動くポーズのデータ16MB、静止ポーズのデータ2MB）を超えるときは、書き出しの途中で **アプリの上限を超えた項目** の画面が1回だけ開きます。既定ではリストの末尾から外すので、残すポーズを選び直して **この内容で書き出す** を押します。選んだ内容はアバターの書き出し設定に保存し、次の書き出しと **アプリに転送（かんたん）** でも使います。外したポーズは書き出し結果の一覧に「同梱ポーズ」として表示します。上限内なら画面は開きません。

保存後は「保存先を開く」でファイルを確認できます。

### ライセンス設定

利用条件を設定する場合は、保存欄の **ライセンス設定** を開き、元の利用規約に合わせてプルダウンを選びます。規約URL（VN3等）、著作権表示、第三者ライセンスも入力できます。設定は出力VRMのメタデータに保存されます。設定を開かない場合は、従来の既定値（作者のみ・個人非営利・クレジット表記が必要・表現用途の各許可なし・再配布と改変なし）で書き出します。

### アプリでの見え方を確認

保存したVRMを、VR Vlogアプリと同じ読み込み処理で開いて確認できます。保存後の **アプリでの見え方を確認** か、メニューの **VR Vlog → アプリでの見え方を確認** で `.vrm` を選びます。

- 材質: アプリと同じ表示（lilToon専用表示）か、標準のMToonだけの表示かを切り替えます。lilToonで表示できたか、MToonで表示した材質の件数と理由を表示します。lilToonは公式のBuilt-in版シェーダーで描くため、アプリのURP版とは細部が異なることがあります。
- 表情: VRMの表情を1つずつ適用し、表情アニメーションを再生します。
- まばたき: 自動のまばたき（4秒ごと）か、目の閉じ具合のスライダーで確認します。自動のまばたきはこの画面だけの確認用の動きで、アプリのまばたきの間隔とは関係ありません。
- 揺れもの: アバターを左右に揺らして揺れものの動きを確認します。

この画面は、VR Vlogアプリの読み込みパッケージ（`com.vrvlog.avatar-runtime`）がプロジェクトに入っているときだけ使えます。このパッケージは一般には配布していません。入っていないプロジェクトでは保存後のボタンを表示せず、メニューの項目は選べません。書き出しは今までどおり動きます。

パッケージを参照するのは `Editor/AppPreview/AvatarRuntimeBackend.cs`（`VRVlog.LilToonExporter.AppPreview` アセンブリ）だけです。画面はこのファイルが登録するインターフェイス（`Editor/AppPreviewEntry.cs` の `IAppPreviewBackend`）だけを使います。パッケージの置き場所や名前が変わったときは、このファイルとアセンブリ定義だけを直します。

## 書き出したVRMをスマホで読み込む

### QRコードで転送する

QR対応の最新iPhone TestFlight版が必要です。Android配布版では受信できません。

PCとスマホをインターネットに接続してください。

1. UnityでVRMを保存し、「QRコードでスマホに送る」を押す。
2. プライバシーポリシーを確認し、同意にチェックを入れる。
3. 「アップロードしてQRを表示」を押し、QRコードを表示させる。
4. VR Vlogアプリで「モデルを変更 → PCから受け取る」を開き、QRを読み取る。
5. ファイル名と容量を確認して受け取る。

**注意**

**QRを持つ人はアバターを受け取れます。他人へ見せないでください。**

転送時は、暗号化したVRMをクラウドへ一時保存します。[転送の詳細・同意事項](Documentation~/CloudTransfer.md)

### 右クリックでアプリに転送する

未リリースの機能です。Hierarchyでアバターの一番上のオブジェクトを右クリックし、**VR Vlog** から2つのどちらかを選びます。QRはスマホのカメラで読み取ります。

| メニュー | 向いているとき | 流れ |
| --- | --- | --- |
| **アプリに転送（かんたん）** | 表情やオブジェクトを選ばずにすぐ送る | 名前・作者名・利用規約の同意を確認 → **QRコードを作る** |
| **アプリに転送（通常）** | 使う表情を選ぶ・不要なオブジェクトを外す | 表情ボードで割り当てる → **次へ：除外するオブジェクト** で外すものを選ぶ → **次へ：名前と利用条件** → **QRコードを作る** |

入力が必要なのは、名前・作者名・利用規約への同意（毎回）・プライバシーポリシーへの同意（初回だけ）です。ライセンスは **VRMの利用条件** を開いて変えられます。開かない場合は前回の設定か既定値で書き出します。

- **かんたん：** 名前と作者名は、このアバターで前に転送したときの値が入ります。書き出す内容は、表情ボードで何も変えずに **アプリに転送（通常）** で書き出した場合と同じです（表情はこのアバターで前に表情ボードで決めた割り当て、無ければ自動で選んだもの。空の neutral と視線は名前から埋め、視線は両目が動く名前がそろったときだけ使います。書き出さないオブジェクトは前回の設定）。違いは、書き出し結果の確認を出さずに転送することだけです。書き出しを止める問題があるときは、理由を表示して止まります。**表情とオブジェクトを選ぶ** で通常に切り替えられます。
- **通常：** 表情ボードの1ページ目で表情を割り当て、**次へ：除外するオブジェクト** を押して外すものを追加し、**次へ：名前と利用条件** を押します。変えた除外は、転送の画面を開く前にプレビューへ反映します。表情の割り当ては [4. 表情を割り当てる](#4-表情を割り当てる任意) と同じです。転送の画面で **戻って編集** を押すと表情ボードに戻ります。

### ファイルを手動で読み込む

1. 書き出した `.vrm` をスマホに保存する。
2. VR Vlogの設定で「lilToon専用表示」をオンにする。
3. 「モデルを変更 → 端末のVRMを選ぶ」でファイルを選ぶ。

## 対応範囲

### 対応するもの

- lilToonの材質・画像
- 表情、ポーズ、瞬き、顔トラッキング用の変形
- Modular Avatarで設定した髪・衣装
- PhysBoneの揺れ物

### 再現しないもの・違いが出るもの

- VRChatのギミック全般、一部のシェーダー効果
- lilToon以外のシェーダーの材質。公式lilToonの材質に置き換え、主画像・色・透過・法線マップ・発光・影色だけを引き継ぎます。元のシェーダーの色調補正は、主画像の明るさを一律に変えるものだけを引き継ぎ、色相・彩度・ガンマ・グラデーション・マスク付きの補正は反映しません。置き換えた材質と、反映しなかった色調補正は保存前に表示します。
- 揺れ方の完全な再現。VRM向けの近似になります。PhysBoneのImmobileは、All Motionのとき揺れの強さと減衰に反映し、Worldのときはアプリの安定化に任せます。
- VRChatと同じ顔・体形。設定によって見た目が異なる場合があります。

他のビューアーではMToon表示になり、見た目や動く表情が異なる場合があります。

### 書き出しで自動的に外すもの

**補助ギミックを自動除外** がオン（既定）のとき、VRMでは働かない次のものを書き出しから外します。外したものと、判断がつかず残したものは書き出し結果の一覧に表示します。

- VRChatの中でだけ動くギミック。Modular Avatarのメニューやアニメーターの組み込みを持ち、カメラ・音・パーティクル・ライト・接触・コンストレイントのどれかを含み、アバターと同じ系統の材質（lilToon・MToonや、体と同じシェーダー）を使っていない見た目を持つものを、そのまま丸ごと外します。体のボーンに付く衣装・小物と、アバターと同じ系統の材質で描かれたぬいぐるみなどの小物は残します。VRChatの中でだけ動く部分が見つからないものは外さずに一覧に表示します。
- Modular AvatarのPlatform Filterで、VRM向けの書き出し（汎用のプラットフォーム）から外す指定があるオブジェクト。含める指定と外す指定が混在しているものは外さずに一覧に表示します。
- 見た目もボーンも持たない空のオブジェクト（VRChatのメニューや設定だけを持っていたものなど）。VRMには入れません。外した数はConsoleに表示します。

外したくないギミックは、表情ボード（「VRM書き出し」と **アプリに転送（通常）**）の2ページ目 **除外するオブジェクト** にある **VRChat用のギミック** で **含める** を選ぶか、「VRMを書き出す」の画面の補助ギミックの一覧で **VRMに入れる** をオンにすると残せます。VRMに入れても、VRChatの中での動きは再現されません。選んだ内容はアバターの書き出し設定に保存し、どちらの画面にも同じ選択が出ます。表情ボードでは、選んだ内容をページを移るときにプレビューへ反映します。**補助ギミックを自動除外** をオフにすると、これらはどれも外しません。

## 困ったとき

<details>
<summary>エラーで書き出しが止まる</summary>

書き出し画面の「書き出しの詳細」を開きます。エラーが起きた対象と、表示された対処方法を確認してください。

対策候補が表示された場合は、再試行できます。成功したら、見た目を確認してVRMを保存してください。

</details>

<details>
<summary>必要なパッケージが足りない・対応版ではない</summary>

「動作環境の確認」画面に、不足しているパッケージや未対応のバージョンが表示されます。画面の案内に従って導入・更新し、もう一度書き出してください。

</details>

<details>
<summary>衣装が出力されない</summary>

Unityで、その衣装が表示されているか確認してください。非表示の衣装は出力されません。表示しても出ない場合は、アバターへの接続設定を確認してください。

</details>

<details>
<summary>瞬きで目がうまく閉じない</summary>

閉眼用の変形を自動で決められないときは、瞬きなしで保存し、警告に理由を表示します。瞬きを入れるときは次の手順で選んでください。

1. 表情ボードの1ページ目にある瞬きの「確認・調整」を開く。
2. 「手動」に切り替え、顔のメッシュと閉眼用の変形を選ぶ。
3. プレビューで目の開閉を確認し、「設定を適用」を押す。
4. VRMを保存する。

</details>

<details>
<summary>解決しない場合の問い合わせ</summary>

[不具合報告](https://github.com/VR-Vlog/VR-Vlog-Avatar-Exporter/issues/new/choose)に、次の内容を添えてください。

- Unityとエクスポーターのバージョン
- 問題が起きるまでに行った操作
- エラー画面でコピーした共有用の診断

VR Vlogアプリ内の問い合わせも利用できます。

</details>
